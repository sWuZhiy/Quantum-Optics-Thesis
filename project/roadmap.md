# 毕设执行路线与研究价值筛选

更新：2026-09-19。这是**建议路线**，具体周期需按导师要求、毕业日期及计算资源调整。主线暂取静态、单模、平衡态 Dicke–Ising；零温先做基线，有限温度和更复杂模型由阶段结果决定。论文与数值结果不可预设为新相或可发表成果。

## 最小模型与三个先例

采用 `ℏ=1`、`s_i^α=σ_i^α/2`、`S_x=Σ_i s_i^x`：

```text
H = ωa†a + ΔΣ_i s_i^z + H_Ising(J)
    + (2g/√N)(a+a†)S_x + [D(g)-ξ](a+a†)² .
```

固定 `H_Ising` 的符号、边界条件、维度与物理平台后再计算；稳定域是 `B=ω+4[D(g)-ξ]>0`。2025 [Langheld 等](https://arxiv.org/html/2409.15082)已有 QMC 相图及补充材料的 A² 映射；2011 [Gammelmark–Mølmer](https://arxiv.org/html/1102.1905v1)已有**量子** Ising–腔有限温度自由能；2026 [Leibig 等](https://arxiv.org/html/2601.10210v1)已有热力学极限自洽物质模型和精细零温相图。Gammelmark 的自旋轴相对方向与本题不同；各论文的近似和算符归一化也需逐式比较，不能在模型不同的情况下声称“完全复现”。

## 按顺序推进

| 阶段 | 要做什么 | 留下的产物与通过标准 | 价值判断 |
| --- | --- | --- | --- |
| 0. 锁定问题 | 与导师核实实际平台、`ξ` 来源、`D(g,J)` 约束、毕设截止日期；选一维 Ising 主线，XXZ 暂不同时展开 | `project/brief.md` 补齐；`theory/` 中有一页模型、参数和“真实平衡/有效基态”定义 | 若独立静态 `ξ` 没有可信来源，把研究定位为有效模型；若由泵浦实现，另立驱动稳态问题 |
| 1. 完成解析骨架 | 手推压缩映射、`B>0` 稳定域、`J=0` 临界线；写出热力学光场位移自由能及自洽条件 | 推导能与 Chen 无相互作用极限及 Langheld 补充材料 §IV 相互核对；明确一级边界不能由线性稳定性判定 | 先排除坐标重标定造成的“伪新效应” |
| 2. 建立可复现代码 | 稀疏精确对角化（ED）实现小链和有限光子截断；同时实现压缩前/后两种表述 | 同一物理点能谱、序参量经算符变换后吻合；对 `N`、光子截断和求解误差作检查；每次运行记参数与代码版本 | 这一步是毕设保底结果，也是以后所有新预测的数值地基 |
| 3. 求热力学相界 | 先用自旋平均场作粗定位，再以自洽的量子自旋链求解器求 `f(x)` 的**全部局部极小值**；零温可由 DMRG / 更大系统计算与文献 QMC 对照 | 连续边界用曲率/响应，一级边界用**全局自由能交叉**；反铁磁共存区用细网格和尺寸检查 | 若仅是 Langheld/Leibig 已知相图经过 `(ω_s,g_s)` 的路径映射，按可达性研究表述，不宣称新相 |
| 4. 选一个有物理意义的延伸 | 优先“平台约束 + 可达窗口 + 可测信号”；有限温度仅在具体问题超过 Gammelmark 的先例时进入；XXZ/多模另行立题 | 一页对照表：新结果、最接近的已发表图/公式、为何对方不能直接给出、参数是否可实现 | 这是决定是否有投稿价值的关口 |
| 5. 稳健性与写作 | 做两个独立方法/极限的交叉检查，固定最终图，记录失败参数和不确定性；写毕设正文 | 每张图可追溯到脚本、输入与文献基准；结论明确分为已知结果、项目计算与推断 | 有超出现有理论的可靠机制/预测再考虑高水平投稿；否则完成扎实毕设 |

建议先按 **1–2 周理论与基线、2–4 周代码和复现、3–5 周相界及价值筛选** 作为工作量估计；不是截止日期承诺。每阶段只推进一种关键难题，避免一开始同时做 XXZ、有限温度、耗散和多模。

## 数值方法按投入排序

| 方法 | 推荐用途 | 优势与主要限制 |
| --- | --- | --- |
| 解析 + 自洽标量自由能 | `J=0`、稳定窗口、连续失稳线和参数路径；热力学极限可写 `f(x)=Bx²/4+f_spin(T,h=2gx)` 并对 `x` 取全局最小 | 最快筛选问题；`f_spin` 必须来自选定自旋模型，不能无条件用单自旋平均场代替量子链 |
| 稀疏 ED / Lanczos | 小 `N` 的零温能谱、光子数、结构因子、一级边界候选；验证压缩映射 | 规模约为 `2^N × (n_max+1)`；尺寸和光子截断很快成为瓶颈，临界点附近尤其如此 |
| 小系统有限温度 ED | 核对配分函数、自由能和温度趋势 | 适合做程序基准，不足以单独证明热力学相变；全谱成本比 Lanczos 高 |
| 自洽量子链 + DMRG | 一维零温的 `f_spin(0,h)`、窄共存区和一级边界 | 比直接保留腔模更易扩展；要找全局自由能，单一起点自洽可能锁在亚稳态；现有 Leibig 方法已做到更高精度，复现本身不是新意 |
| 有限温度张量网络 / 专用 QMC | 大链热自由能、响应和临界区 | 难度明显更高；先确认科学问题及硬件资源，QMC 的权重、更新规则和误差分析需要专门验证；不作为毕设入门门槛 |

`x=⟨a+a†⟩/√N` 是热力学标量位移。上式中的 `f_spin(T,h)` 是给定均匀横场 `h` 后**相互作用自旋链**每个自旋的自由能；对当前 `ΔΣs^z + JΣs^zs^z + hS_x`，一般不能直接沿用只有一个横场的可积 Ising 链公式。有限尺寸的对称本征态通常有 `⟨a⟩=0`，应同时计算光子密度、正交分量及自旋的均匀/交错结构因子，或说明取破缺对称极限的顺序。一维短程链的反铁磁长程序通常在任何 `T>0` 消失；当前腔项耦合均匀 `S_x`，不能想当然地把零温 AFM 共存相向上延伸成热相。若核心问题必须包含有限温度 AFM 长程序，就要重新考虑二维或额外长程相互作用，并接受更高数值成本。

## 研究价值的停走问题

每得到一张新相图，依次问：

1. 该特征是否仅是已知 `(ω_s,g_s,J,T)` 相图的一条控制路径？
2. `B>0`、平台参数与 `D(g,J)` 约束下能否到达？若 `ξ` 来自泵浦，能否仍称实验室系平衡？
3. 是否有超出相界平移的预测，例如新可达窗口、可区分相的测量信号，且前人未已给出？
4. 一级边界、窄共存区、临界指数是否通过自由能、截断和热力学极限交叉检查？

只有问题 2–4 都有肯定且可核查的答案，才将它当作潜在论文主结果。否则保留为严谨毕设章节，并在 `project/decisions.md` 记录转向依据。
