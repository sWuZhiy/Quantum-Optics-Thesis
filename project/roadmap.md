# 阶段计划

具体日期在确认学校和导师要求后填写。

| 阶段 | 产物 | 完成标准 |
| --- | --- | --- |
| 选题 | 项目简述、问题边界 | 问题、模型和可交付结果明确 |
| 文献 | 文献矩阵、核心论文笔记 | 能说明现有工作与待研究问题的关系 |
| 理论 | 模型、符号表、主要推导 | 假设和适用范围清楚，关键公式可复核 |
| 计算/实验 | 可重复运行的程序或流程 | 有参数记录、基准检查和原始结果 |
| 分析 | 图表及误差/局限讨论 | 每张图可追溯到输入和生成方法 |
| 写作 | 论文草稿、修改记录、终稿 | 引用、图表、格式与结论核对完成 |
