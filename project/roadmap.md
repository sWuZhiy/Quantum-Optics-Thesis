# 投稿潜力导向的执行路线

`FT-TC` 是本项目的工作代号，展开为 **Finite-Temperature Tricriticality（有限温三临界结构）**：研究零温量子 Dicke–Ising 三临界结构能否及如何延伸到有限温度。这里的 `TC` 不指 Tavis–Cummings，也不预设有限温三临界点一定存在。

更新：2026-11-21。本文是当前可执行计划，不表示正式题目已经获得导师确认。[P0 验收](p0-gate-review-2026-11-21.md)已完成文献、增量假设与本机方法预审：解析正常态曲率、周期热 ED、开边界 NLCE 和无限空间链转移矩阵在目标铁磁截面做了交叉。**技术路线定向可行；正式 P0 放行暂缓**，因为用户与导师尚未接受题目范围，Leibig 期刊正文尚未取得，完整零温相界尚未复现。下一步允许做 Z 校准，暂不开展完整热相图。统一[模型文档](../theory/model.md)已建立，尚无新相图。

## 0. 当前路线状态

| 路线 | 状态 | 用途 |
| --- | --- | --- |
| 静态同正交分量 `A²-ξ` + 自旋相互作用的简单加项/扫参 | **已停止作为创新主线** | 只保留精确映射、稳定域和原光子观测量作为解析基线 |
| `FT-TC`：轴向匹配的量子 Dicke–Ising 有限温三临界延伸 | **首要活动候选，P0 正式放行暂缓** | 技术预审已做；先复现零温基线并确认题目范围，再决定完整热研究 |
| 零温 Dicke–Ising | **校准基线** | 复现已知相界、三临界条件和有限尺寸行为，不声称原创 |
| `CL-AF`：同轴经典链反铁磁竞争 | **搁置为算法基准/后备** | 验证全局自由能、多分支和一级边界代码 |
| 耗散、多模、不同正交分量、时变或非高斯扩展 | **未立项** | 每个方向都须另写模型和查重，不作为自动退路 |

活动主张及否决条件见 [`claims.md`](claims.md)。本路线只安排仍有理由投入的工作；旧任务的淘汰证据保留在 [`decisions.md`](decisions.md) 与 [`research-assessment.md`](research-assessment.md)。

## 1. 成功标准与止损规则

投稿候选至少同时满足：

1. 相对最近先例有逐算符、逐参数写清的差异，而不是只换名称、扫描方向或数值方法。
2. 关键结论来自全局自由能或受控热力学极限；有限系统平滑变化不称为热相变。
3. 至少有一种独立检查，例如解析极限与 ED、两种数值方法，或不同系统尺寸/截断的收敛。
4. 每张图能追溯到代码、配置、版本和输入，负结果也保留运行说明。
5. 结论明确区分平衡热相变、开放系统稳态相变和量子模拟器有效基态。

止损规则：文献发现同一模型和目标相图已被完整覆盖，或在约定资源内无法给出受控热力学结论时，立即更新主张台账并停止完整扫参；不得用已经投入的时间作为继续理由。

## 2. P0：先验证问题值得做

### P0.1 建立文献差异矩阵

交付：`literature/ft-tc-gap-matrix.md`。

至少逐式比较：

- Gammelmark–Mølmer（2011，DOI `10.1088/1367-2630/13/5/053035`）：有限温配分函数、自由能与一/二阶超辐射边界；重点写清交换轴、静态场和腔耦合轴。
- Langheld–Hörmann–Schmidt（2025，DOI `10.1103/lcvj-ksct`）：零温 QMC 相图；补充 §IV 式 (S33)–(S35)、图 S9 的 `A²` 可达性。
- Leibig 等（2026，DOI `10.21468/SciPostPhys.21.3.071`）：正文式 (1)–(3)、零温自洽物质模型和热力学相图。
- Koziol（2026，arXiv:2605.27484v2）：摘要和正文 Landau 推导中的零温三临界机制与标度。
- Hörmann（2026，arXiv:2606.26081v1）：§II 的自洽泛函、§V.3 的零温边界及 §VI 的开放问题。
- Wang–Li–Chen（2026，arXiv:2602.09912v1）：开放横向/纵向 Dicke–Ising；当前只把摘要报告的稳态双稳和四临界结构作为“耗散路线已有先例”的边界，进入该路线前须精读正文。

验收：能用一页表格回答“本项目哈密顿量与每篇文献究竟差在哪个算符、极限、温度或动力学对象”，并列出前向引文和检索式。没有清楚差异则 `FT-TC` 不进入计算。

### P0.2 写一页新颖性与可证伪备忘

交付：`project/novelty-memo.md`。

必须包含候选核心命题、最近先例、最小可发表结果、最可能的反例、停止条件和导师需确认的问题。措辞用“定向检索尚未发现”，不用“首次”或“无人研究”。

### P0.3 方法与资源可行性

交付：`project/method-feasibility.md`。

比较至少三条层级：

- 热力学极限自洽自由能 + 一维量子链有限温求解；
- 小系统热 ED，只作公式、代码和有限尺寸交叉检查；
- 有限温张量网络、NLCE 或 QMC 中至少一种可扩展方案。

写明系统尺寸、Hilbert 空间、温度网格、内存/时间估计、一级边界的全局分支处理和独立验证方法。若资源只够小系统平滑交叉，不能把路线包装成有限温相图研究。

### P0 放行条件

只有同时满足以下条件才进入 T 阶段：

- 没有找到完整覆盖同一模型与目标问题的先例；
- 能明确写出相对先例的最小增量；
- 至少一条热力学极限方法在本机或可获得资源上可行；
- 用户与导师接受该题目范围。

## 3. Z：零温与解析校准，不作为创新

统一取 `ℏ=k_B=1`、`s_i^α=σ_i^α/2`、`S_x=Σ_i s_i^x`。候选基线为

```text
H = ω a†a + Δ Σ_i s_i^z + 4J Σ_i s_i^z s_{i+1}^z
    + (2g/√N)(a+a†)S_x + [D(g)-ξ](a+a†)²,
```

其中 `J>0` 反铁磁、`J<0` 铁磁，先取偶数周期链；模型和边界条件最终写入 `theory/model.md`。

### Z1 精确光子变换

记 `q=D-ξ`。在 `ω>0`、`ω+4q>0` 内复算

```text
r = (1/4) ln[1+4q/ω],
ω_s = √[ω(ω+4q)],
g_s = g[ω/(ω+4q)]^(1/4).
```

交付：`theory/derivations.md`，包含常数项、有限温配分函数等价、原 `a` 的数目与正交分量映射。用截断小矩阵在多个稳定点核对变换前后低能谱；靠近稳定边界时做光子截断收敛。

### Z2 零温相图校准

复现一个铁磁连续/一级截面和一个反铁磁共存截面，参数直接取自 Langheld 或 Leibig；同时核对 Koziol/Hörmann 的三临界条件。交付：版本化配置、运行目录、收敛表和仅供审查的图。验收目标是暴露符号、分支和有限尺寸错误，不把复现图作为投稿新结果。

## 4. T：通过 P0 后的有限温主任务

### T1 推导自由能泛函

从明确哈密顿量推导 `Z=Tr exp(-βH)` 与热力学极限自由能泛函，定义所有序参量和单位。证明所用鞍点/自洽步骤的适用范围；一级边界必须比较所有局部稳定分支的全局自由能。

### T2 建立小系统热基准

实现小 `N` 热 ED，核对 `J=0`、`g=0`、`T→0`、高温熵和精确压缩映射。ED 只用于单元测试和有限尺寸估计，不据此宣称有限温热相变。

### T3 热力学极限求解

实现 P0.3 选定的可扩展方法，先获得无 `D-ξ` 的核心相图。追踪二次与四次 Landau 系数、全局能量交叉、三临界线或临界终点；同时保存亚稳分支，避免局部优化漏掉一级边界。

### T4 收敛与独立验证

系统检查链长/键维、温度步长、优化初值、截断和误差；至少用小 ED、解析极限或第二算法交叉验证关键点。随机算法记录随机种子。

### T5 受约束路径与可测量量

只在 T3 已形成可信新结果后，再加入 `D(g)`、`ξ` 路径，研究相界可达性和原光子观测量。必须把“相图本身的结构”与“实验路径如何穿越既有结构”分开陈述。

## 5. V：投稿前否证检查

- 用完成时的最新前向引文和关键词重新查重。
- 主动搜索能解释结果的简单映射、坐标重标定或有限尺寸伪影。
- 对每个核心图写一句可证伪结论和适用范围。
- 由另一套极限或实现独立复查至少一个关键相界和一个三临界点。
- 若结果是负的，判断它是否给出严格边界或有用的排除结论；否则转为内部基准，不强行包装。

## 6. W：写作与可复现交付

推导写入 `theory/`；可复用代码写入 `code/src/`，单元测试写入 `code/tests/`；配置、代码版本、参数和日志写入 `results/runs/`；只有审查通过的图进入 `results/figures/`。原始外部数据不覆盖。论文中对文献报告、作者解释、本项目计算和我们的推断分别标注。

## 7. 搁置路线的重启条件

- `CL-AF`：只有找到具体腔平台约束、非平凡光子统计或现有混合范围 Ising 文献未覆盖的清楚增量才重启；否则仅用于自由能代码基准。
- 开放/耗散：先与 Wang–Li–Chen（2026）逐式比较 Lindblad 通道、稳态结构和近似；不能把稳态相变称为平衡热相变。
- 不同正交分量、多模、时变或非高斯模型：先证明新增项不能被单模静态压缩变换消去，再建立独立 P0，不与 `FT-TC` 同时展开。

2. 取得 Leibig 期刊正文后核对 arXiv v1 的公式/图与有限温讨论；定题前再查最新同模型论文。若发现完整热相图，立即按 C04 止损。
