# 量子光学毕设：执行路线、数值任务与研究价值筛选

更新：2026-09-19。本文是可执行的**工作计划**，不是已完成的计算或已与导师确认的题目。按阶段推进；预计周数只是工作量参考，待学校节点、课程负担和电脑资源明确后再排日历。研究主线暂定为**静态单模、平衡态 Dicke–Ising**，先做零温，再决定是否有足够理由研究有限温度。XXZ、多模和耗散暂不同时展开。

## 0. 先明确研究问题与成功标准

暂定核心问题：在明确的物理参数约束下，反压缩强度 `ξ` 与自旋交换 `J` 如何改变超辐射相、磁序以及二者共存区域的**可达性和可测信号**？不能把“添加一个二次项”当作创新。已有 [Langheld 等（2025）](https://arxiv.org/html/2409.15082)的 Ising QMC 相图及 A² 补充分析、[Gammelmark–Mølmer（2011）](https://arxiv.org/html/1102.1905v1)的量子 Ising 有限温度自由能，以及 [Leibig 等（2026，预印本）](https://arxiv.org/html/2601.10210v1)的自洽量子链零温相图。

**毕设最低交付**：明确模型与物理边界；可复现 `J=0`、`ξ=0` 两类基准；一套收敛检查充分的参数路径及光/磁观测量；解释其与已有相图的关系；完成规范写作。**更强的论文候选**还需可信的平台约束、前人未直接给出的可达窗口或测量预测，以及独立方法验证。

## 1. 工作模型：先统一符号，再写程序

使用 `ℏ=k_B=1`，`s_i^α=σ_i^α/2`，`S_x=Σ_i s_i^x`。建议统一为下式；`J>0` 表示反铁磁，`J<0` 表示铁磁，先取偶数 `N` 的周期链：

```text
H = ω a†a + Δ Σ_i s_i^z + 4J Σ_i s_i^z s_{i+1}^z
    + (2g/√N)(a+a†)S_x + [D(g)-ξ](a+a†)².
```

这里的 `4J s_i^z s_{i+1}^z=Jσ_i^zσ_{i+1}^z`，可直接与 Langheld 的符号比较，其 `ε=Δ/2`。工作中要分别标出 `D(g)` 的**纯数学示例**（例如 `κg²`）和从实际器件推导的关系；在没有后者之前，不宣称真实无泵浦装置实现了独立静态 `ξ`。

记 `B=ω+4[D(g)-ξ]`。`B>0` 是当前二次光场模型有下界的必要条件。对每一组稳定参数，光子压缩变换给出 `ω_s=√(ωB)`、`g_s=g(ω/B)^(1/4)`；所有平衡态相图必须先与这组变换后的已知模型比较。零温的连续失稳可用自旋横向磁化率初筛；**一级转变必须比较全局能量/自由能**。

## 2. 阶段任务与验收门槛

### 阶段 A：锁定平台和模型（建议 1 周；可与导师沟通并行）

1. 在 [项目简述](brief.md)填入毕业时间、中期检查、可用 CPU/内存、导师允许的理论与数值工作量。
2. 选定一项主张：①只研究静态**有效哈密顿量**；②从具体无泵浦平台推导 `D(g)` 与 `ξ`；③若 `ξ` 必须由泵浦得到，明确改为驱动稳态问题。未确定时按①开展数值基线，论文如实标注。
3. 在 `theory/model.md` 固定哈密顿量、全部参数单位、`J` 符号、边界条件、守恒量/对称性、稳定区和两个需复现的文献截面。

**通过标准**：任意代码参数都能无歧义地对应到一篇参考论文的模型；能说明平台假设。**停止扩题条件**：`ξ` 的来源尚不清楚时，不写“规避禁戒”或实验室系热平衡结论。

### 阶段 B：解析基线（建议 1–2 周）

1. 在 `theory/derivations.md` 手推压缩变换、常数能量项、原光场观测量的反变换和 `B>0` 条件；核对 Chen 主文/补充材料及 Langheld 补充材料 §IV。
2. 对 `J=0` 推导正常相失稳线 `B=4g²/Δ`；对 `g=0` 核查自旋链的磁性基线。
3. 写出热力学位移变量 `x=⟨a+a†⟩/√N` 的自由能密度：`f(x)=Bx²/4+f_spin(T,h=2gx)`，其中 `f_spin` 是**相互作用自旋链**在均匀场 `h` 下的每自旋自由能。对所有 `x` 极小值而非单一自洽解比较能量。
4. 对示例 `D=κg²` 分析稳定区与 `K=g²/B` 随 `g` 的变化，排除以 `g_s(g)` 的形状直接宣称重入。

**通过标准**：`J=0` 解析线、`ξ=0` 的 A² 变换与文献一致；注明磁化率判据只识别连续失稳，不能定位一级相界。**产物**：两页推导、符号表、三个极限的核对记录。

### 阶段 C：可复现的小系统数值（建议 2–4 周）

1. 选 Python 稀疏矩阵作为第一版：`code/src/model.py` 构造自旋与光子算符，`code/src/ed.py` 求低能本征态，`code/src/observables.py` 计算观测量，`code/src/sweep.py` 管理参数扫描。探索 notebook 可以保留，但最终图必须可由脚本再生。
2. 先算 `J=ξ=D=0` 的标准 Dicke 模型，再算 `J=0` 且 `D,ξ≠0`，最后算 `ξ=0` 的 Ising 截面。不要第一天就扫描完整四维参数空间。
3. 推荐首批偶数链 `N=4,6,8`，光子截断从较小值逐步加大；总 Hilbert 空间维数约为 `2^N(n_max+1)`。靠近 `B=0` 或超辐射区时截断尤其敏感，以观测量收敛而非固定的 `n_max` 判定。
4. 每次运行记录 `ω,Δ,J,g,D,ξ,N,n_max`、边界条件、求解器容差、代码提交号与运行时间；数据留在 `results/runs/`。输出基态能量、低能隙、`⟨a†a⟩/N`、两个光场正交分量方差、均匀和交错自旋结构因子。
5. 计算压缩前后的同一物理点。无限光子空间中两者严格幺正等价；**有限截断只要求随 `n_max` 增加趋于一致**。有限 `N` 的对称本征态可有 `⟨a⟩=0`，不能据此判为正常相；用二阶量/结构因子或说明破缺对称极限。

**通过标准**：程序通过解析 `J=0` 极限；低能谱与观测量对 `n_max` 收敛；复现文献至少一个无自旋相互作用截面与一个 `ξ=0` 截面。可先将能量密度变化控制到约 `10⁻³`、关键观测量到约 `1%`，临界点附近须报告实际误差和尺寸漂移，不能机械套阈值。

### 阶段 D：从小系统走向相界（建议 3–5 周）

1. 对固定 `J` 先扫一维 `g` 路径；找出可疑相界后才做局部的 `g–ξ` 或 `J–ξ` 图。每张图必须遮掉 `B≤0` 区域，并标出使用的 `D(g)`。
2. 用 `f(x)` 的多起点/网格搜索找到全部候选极小值。连续边界用曲率或磁化率交叉核对；一级边界用不同极小值的**全局自由能交叉**及序参量跳变核对。迟滞或一次自洽迭代失败只能当线索。
3. 自旋求解先用简单近似粗定位，再选择一个可靠升级：一维零温优先自洽量子自旋链 + DMRG；若现有资源不足，保留解析线和受控 ED，并把热力学结论限定在能验证的范围。大型 QMC 及 NLCE+DMRG 不设为毕设必过门槛。
4. 对反铁磁共存区使用细网格；与 Langheld QMC、Leibig 热力学结果及 Mendonça/Comment 的争议逐图对照。对每个候选相记录其光序与交错结构因子，而不是只依靠光子数命名。

**通过标准**：至少一条有说明的参数路径，给出稳定域、相界、能量比较、两类序参量和尺寸/截断误差；已知基准的偏差有明确原因。**禁止结论**：小尺寸平滑曲线不能独自证明一级相变或“新相”。

### 阶段 E：筛选真正值得深入的结果（建议 1–2 周）

为每个候选效应填一行：`现象—参数—最近文献及公式/图—压缩映射是否已解释—平台可达性—独立验证—可测信号`。优先研究**物理约束下此前没有定量给出的可达边界**，并结合原光场噪声与磁序提出可分辨的诊断。必须区分三种结果：

- **已知**：相区或一级边界本来存在，只是 `ξ` 改变了控制路径；作为毕设分析，不宣称新机制。
- **增量**：某个具体平台的稳定窗口、反压缩阈值或实验可读出的联合信号此前未量化；继续交叉验证，评估专题论文。
- **强新意候选**：微观可信、不能被当前单模变换化掉的机制，并有解析解释与独立数值证据；才评估高水平投稿。

**停走标准**：若所有候选结果都能由已知相图精确映射得到，就完成扎实毕设，不无限扩大参数扫描；若确有强候选，再与导师讨论平台、合作及投稿目标。

建议用 `S_π^z=N⁻² Σ_{ij}(-1)^{i-j}⟨σ_i^zσ_j^z⟩` 衡量有限系统的交错关联，并注明这个归一化和边界条件；在有限系统中直接的交错磁化期望值可能因对称性为零。原光场 `X=(a+a†)/√2`、`P=(a-a†)/(i√2)` 的方差要用原算符求，不能把压缩象 `b` 的光子数直接当成真实可测光子数。

### 阶段 F：条件延伸与写作（并行，时间依具体结果）

- **有限温度**：先写清与 Gammelmark–Mølmer 模型的自旋轴、`D(g)` 和平台差别，再以小系统热 ED 核对 `Z` 与自由能；更大系统可考虑有限温度张量网络或专用 QMC。一维短程反铁磁长程序通常在任何 `T>0` 消失，当前腔只耦合均匀 `S_x`，不要预设零温 AFM 共存相延伸成有限温度 AFM 热相。若研究焦点必须是有限温度反铁磁长程序，需重新评估二维/长程相互作用及计算量。
- **XXZ、多模、非线性或耗散**：每次只选一个，先检索最近论文并写新的模型、稳定条件与数值预算；不能把泵浦旋转框架的有效基态直接当真实热平衡。
- **写作**：阶段 A 后同步维护 [LaTeX 调研笔记](../thesis/notes/main.tex)；阶段 C 后方法章节写代码/收敛；阶段 D 后才写结果与讨论；正式投稿或毕业提交时再依导师与学校格式迁移模板。

## 3. 每次计算的记录格式

`results/runs/<日期>-<短名称>/` 保存 `params.json`、`environment.txt`、`summary.json`、原始输出和绘图脚本版本；大量生成数据默认不提交 Git，保留可再生脚本和最终核验图。`params.json` 至少包含模型/边界条件、所有参数、`N`、`n_max`、求解器容差和随机种子（若方法用随机数）。最终图只放 `results/figures/`，图注写参数、误差/收敛和相应文献基准。原始数据不覆盖。

## 6. 最近一次工作会话可以直接做什么

1. 将本页“工作模型”写成 `theory/model.md`，附上 Langheld 与 Chen 两套符号的对照表。
2. 写出 `B>0`、`ω_s,g_s`、`J=0` 临界线的逐步推导，检查 `D=ξ=0` 极限。
3. 在 `code/src/` 建立最小稀疏 ED，先只算 `N=2,4` 的标准 Dicke 模型；第一张图为 `J=D=ξ=0` 时光子密度随 `g` 变化，并标解析临界值和有限尺寸说明。
4. 运行前选定参数和验收标准，完成后把结果与下一步决定写入[进度记录](progress.md)。
