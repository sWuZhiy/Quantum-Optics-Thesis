## 热力学自由能的目标表达式

在 `N→∞`、单模频率 `ω>0`、集体耦合按 `1/√N` 缩放且 `ℏ=k_B=1` 的平衡模型中，令实腔位移 `a≈√N φ`。定义短程物质链在均匀横场 `h_x` 下的单位点自由能

```text
f_spin(T,h_x;J,Δ) = −lim_(N→∞) [T/N] ln Tr_spin exp{−[ΔΣsᶻ+4JΣsᶻsᶻ+h_xΣsˣ]/T}.
```

则候选全局自由能密度为

```text
f(T;g,J,Δ) = min_(φ∈R) Φ_T(φ),
Φ_T(φ) = ω φ² + f_spin(T,4gφ;J,Δ).
```

这沿用单模集体耦合的热力学自洽原理，不是本项目新推导；可核对 Román‑Roche 等（2021，[arXiv:2011.03753](https://arxiv.org/html/2011.03753)）主文自洽模型、补充 §III.2 的有限温响应，以及 Hörmann（2026，[arXiv:2606.26081](https://arxiv.org/html/2606.26081)）§II 的一般泛函和文献溯源。这里对任意非零温度的严格适用条件、交换极限的细节仍需逐式复核；有限 `N` 不可直接把上式当作精确配分函数。

驻点满足 `2ωφ+4g m_x(T,4gφ)=0`（`m_x=⟨Σs_i^x⟩/N`，横场在物质哈密顿量中取 `+h_xΣs_i^x`）。定义 `χ_x=−∂m_x/∂h_x|_0≥0`，正常态局部失稳条件为 `2ω−16g²χ_x=0`。它只给**局部**连续边界；一级跃迁要扫描 `Φ_T` 的全部局部极小值并比较全局值，不能只迭代一条自洽分支。此处因子可由 `J=0,T=0` 检查：单自旋 `χ_x=1/(2Δ)`，得到原文的 `g_c²=ωΔ/4`；仍须独立代码复算。

### 第一个可复算的热基准：`J=0`

取 `Δ>0`、`J=0`、`q=D-ξ=0`，保持上述 `s=σ/2` 和 `ℏ=k_B=1` 约定。此时物质是独立二能级系统，热力学极限自由能可手算为

```text
Φ_T(φ) = ωφ² − T ln[2 cosh(√(Δ²+16g²φ²)/(2T))],   T>0.
```

在 `φ=0` 展开得到连续边界的局部条件 `g_c²(T)=ωΔ/[4 tanh(Δ/(2T))]`，其 `T→0` 极限为 `ωΔ/4`。这是已知 Dicke 极限的归一化与程序基准，**不是新结果**；一级边界仍须比较全局极小值。2026-11-19 用本项目 NumPy 环境在 `ω=Δ=1,T=0.5` 检查了此公式的有限差分二次系数，阈值 `g_c≈0.57293876` 时系数约 `5.9×10⁻⁷`（步长 `10⁻³`），只验证公式因子，不替代程序或收敛基准。

## 可行求解路线与验收

| 阶段 | 计算办法 | 必要检查与止损 |
| --- | --- | --- |
| Z0 符号与极限 | 手算 `J=0` 的单自旋自由能；独立写小系统精确对角化，检查 `g=0`、`T→0` 与 `ω,Δ,J` 约定。 | 与 Dicke 阈值及已有零温 Ising 相界同一归一化；不通过则停止热计算。 |
| T0 物质自由能原型 | 一维非可积 `zz` 链加 `z/x` 双场：可用有限温张量网络/转移矩阵求 `f_spin(T,h_x)`；小 `N` 精确配分函数用于交叉。 | 同一 `h_x,T` 对系统尺寸、虚时间步长/截断、键维收敛；`f_spin` 必须足够精确以分辨相近自由能极小值。 |
| T1 相界 | 在多初值、全范围 `φ` 上搜索局部极小值，再以共同切线/等自由能求一级边界；连续边界另用 `χ_x` 与曲率核对。 | 用密集网格仅作找分支，最终以收敛自由能判定；检查 `T→0`、高温及 `J→0`；若误差大于自由能差，停止宣布一级线。 |
| T2 相区和光场量 | 对磁序、光子密度及原正交分量给出自洽态与回代关系；必要时与直接有限尺寸全光子模型交叉。 | 按 `1/N`、光子截断及统计/张量网络误差分别报告。静态 `A²−ξ` 路径只能作为从属问题。 |

## 本机资源与剩余风险

本机已配置的解释器 `D:\codex\quantum-optics-env\python.exe` 可用；2026-11-18 检查仅发现 `numpy`，未发现 `scipy`、`quimb`、`tenpy`、`itensor`、`torch`、`jax` 或 `matplotlib`。`code/environment.yml` 目前只声明 Python 3.12 和 pip。无需现在安装大型包；先选定求解器并明确最小基准，再按仓库 `AGENTS.md` 的 `--prefix` 与包缓存规则安装。项目尚无 `code/src/` 求解器、`theory/model.md` 或 `results/runs/` 中的研究运行。

**可行性判定仍未通过**：在只有 NumPy 的环境下可做小 `N` 验证，无法凭现有项目能力宣称大系统非可积链的热自由能或三临界线。下一轮先确定一个可复现的有限温物质链求解器、目标尺寸与温度窗口，并运行一个全局自由能基准。若无法控制一级边界的误差，`FT-TC` 可作为毕设复现课题，但不满足当前投稿候选标准。

**最小 P0.3 实操验收**：先把上面的 `J=0` 解析式做成可复算脚本；再用小尺寸自旋链热迹检查一个 `J≠0,Δ≠0,T>0` 截面的 `f_spin(T,h_x)`。小尺寸热迹只用于交叉检验，不能代表热力学极限。选择一条可扩展的有限温链算法后，对同一截面报告尺寸或键维、虚时间步长（如适用）和自由能误差；误差必须小于待区分的极小值自由能差，才有资格追踪一级边界。此项尚未执行。
