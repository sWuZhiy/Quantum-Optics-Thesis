# 研究主张台账

更新：2026-11-20。

本文件只管理“现在允许对外说什么、还需验证什么、何时停止”。详细文献证据见 [`literature/reading-list.md`](../literature/reading-list.md)，方向变更理由见 [`decisions.md`](decisions.md)。状态含义：

- **活动候选**：值得继续验证，但不是已经确认的创新或结论。
- **基线成立**：有解析或原文证据支持；只能作为方法与一致性检查。
- **已淘汰**：不得再作为项目核心贡献；保留是为了避免重复犯错。
- **搁置**：当前不投入主线资源，只有出现明确差异和证据时才重启。

## 更新规则

1. 新主张先登记为“活动候选”，写清模型、证据、反证条件和最便宜的下一检验；没有这些要素，不进入 `brief.md` 或 `roadmap.md`。
2. 原文、作者解释、我们的推断分别记录；“未检索到”不得写成“尚无人研究”。
3. 一项关键先例或反例足以否定活动主张时，立即从当前入口撤下，并在本表与 `decisions.md` 保留淘汰理由。
4. 活动候选通过文献缺口、解析一致性、独立数值验证和可复现性四道门槛后，才可升级为论文核心结论。
