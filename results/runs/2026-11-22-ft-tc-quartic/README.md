研究对象是 [`theory/model.md`](../../../theory/model.md) 的**平衡有效哈密顿量**，取 `ℏ=k_B=1`、`ω=1`、`J=-0.2`（铁磁）。本轮实现并验证了固定 `T>0` 时物质自由能小横场展开的四次系数

```text
f_spin(T,h) = f_0 + a2 h^2 + a4 h^4 + O(h^6),
Phi_T(phi) = omega phi^2 + f_spin(T,4g phi)
           = Phi(0) + [omega + 16 g^2 a2] phi^2 + 256 g^4 a4 phi^4 + O(phi^6).
```

`a4` 的符号在 `g_local` 处决定局部失稳的阶数（正=连续，负=一级），`a2=a4=0, a6>0` 是热三临界点的局部必要条件。本轮只提供**局部 Landau 系数**，不是相界、三临界点或投稿级结论。

## 解析结构（修正后）

在 `h=0` 的经典链中，格点 `i` 的虚时间对传播子是对角的 c 数：

```text
sigma_x_i(t1) sigma_x_i(t2) = exp(-dE_i |t1-t2|),
dE_i = -s_i [Delta + 2J (s_{i-1}+s_{i+1})].
```

不同格点算符对易，故 k=4 时序振幅按格点因子化（**不存在交错时序修正**，也不需要相邻双翻转修正 `D2`；此前推导中关于交错时序的中间态 `c^{ij}` 的分析是错误的）：

```text
Z2/Z0 = (1/4) <sum_i B1(dE_i)>,
Z4/Z0 = (1/16) < sum_i I(dE_i,dE_i) + sum_{i<j} B1(dE_i) B1(dE_j) >,
a2 = -(T/N)(Z2/Z0),  a4 = -(T/N)[Z4/Z0 - (Z2/Z0)^2/2],
B1(x) = int_0^b dt (b-t) e^{-x t},
I(a,c) = int_{u+v+w<=b} (b-u-v-w) e^{-a u - c v} du dv dw
       = int_0^b dt4 int_0^{b-t4} dv int_0^{b-t4-v} dw int_0^{b-t4-v-w} du e^{-a u - c v}.
```

`I` 的全部闭式与退化分支（`a=0`、`c=0`、`a=c`）见 [`ft_tc_quartic.py`](../../../code/src/ft_tc_quartic.py) 模块 docstring；无限链的 r=1 直接 4 自旋窗口与 r≥2 次主导本征空间几何级数同 [`ft_tc_normal_curvature.py`](../../../code/src/ft_tc_normal_curvature.py) 的三自旋概率约定。无限链公式：

```text
a4^inf = -(T/16)[<I_00> + sum_{r>=1}<B1 B1>_c(r)] + (T/32) <B1>^2.
```

## 数值可靠区间

- 直接公式在 `T>=0.1` 可靠：活化构型贡献 `e^{-b dE} * B1(-dE) ~ e^{-b|dE|} e^{+b|dE|} = O(1)`，其中间乘积随 `T` 下降按 `e^{+/-b}` 增长；`T=0.1` 时量级约 `e^{+-20}`（双精度相对误差约 1e-16，结果绝对误差 <1e-9），`T=0.01` 时达到 `e^{+-100}`，中间量超出双精度，直接求值不可用。
- 因此 `T->0` 的锚点不通过直接公式检验，改用稠密 ED 基态能量的解析参考（见上）。
- 无限链公式要求次主导转移本征值与 Perron 根分离（相关长度有限）；铁磁侧 `T>=0.1` 满足。
