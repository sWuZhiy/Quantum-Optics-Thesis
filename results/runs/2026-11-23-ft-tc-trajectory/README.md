## `Delta>.4` 的双根窄袋

零温三临界比值为 `Delta=-2J=.4`。在它上方极窄范围，`a4(T)` 随升温按
“正 → 负 → 正”变化，因而有上下两个候选根：

| `Delta` | 下根 `T_lower`（连续→一级） | 上根 `T_upper`（一级→连续） |
| ---: | ---: | ---: |
| .400100 | .1025485610 | .1382333090 |
| .400200 | .1144160145 | .1337706193 |
| .400240 | .1198830671 | .1304274932 |
| .400255 | .1232446610 | .1277894631 |
| .400258 | .1247195001 | .1264552300 |
| .400300 | 无根 | 无根 |

所以 `(.4,.1411223)` 只是**上分支经过 `Delta=.4` 的点**，不是端点。
真正的两根汇合端点为

```text
Delta_end = 0.400258514826710
T_end     = 0.125599429123184
g_end     = 0.547746132926194
```

## 修正后的拓扑解释

- `Delta<.4`：零温为一级侧；只见上根，升温后转为连续侧。
- `Delta=.4`：`T=0` 的四次系数为零；任意已分辨的小正温先进入极薄一级侧，
  再在 `.1411223` 穿过上根。
- `.4<Delta<Delta_end`：零温为连续侧，但中间温度出现由下根与上根夹住的
  **重入一级窄袋**。
- `Delta=Delta_end`：上下根在有限温切触并消失；更大 `Delta` 在所查温区无根。

因此零温三临界点 `(.4,0)` 是下分支的零温锚点；上分支继续越过 `.4`，最终与
下分支在 `(.4002585,.1255994)` 汇合。初始“候选线终止于 `(.4,.141)`”的表述撤回。

## 边界

- 轨迹来自局部 `a4=0,a6>0`，还需全局 `g_equal` 驻点验证才能成为相界。
- 自动根扫描下限为 `T=.08`；下分支从 `(.4,0)` 到约 `T=.08` 的连接由零温
  解析符号与连续性支持，未在本轮直接数值追踪。
- 端点四阶信号很小，但无限链与 `N=8,10,12` 的坐标及正 `a6` 收敛一致；仍不把
  双精度残差当作严格误差界。
