# FT-TC 热三临界局部验收与 `g_equal` 下确界收敛（2026-11-23）

本轮按用户指定只验收两项：`a_6(T*)>0`，以及 `T*` 邻域
`inf_(h>0) g_equal(T,h)` 是否从一级侧的有限 `h` 最低连续退到
`h→0` 的 `g_local`。研究对象是[统一模型](../../../manuscript/theory/model.md)中的
**平衡有效哈密顿量**，取 `hbar=k_B=1`、`J=-0.2, Delta=0.2,
omega=1`。结果是数值上强支持的热三临界候选，不是完整热相图或数学证明。

## 先纠正上一轮四阶公式

[2026-11-22 四阶记录](../2026-11-22-ft-tc-quartic/README.md)把所有双格点四翻
路径因子化为 `B1(dE_i)B1(dE_j)`。这对不相邻格点成立，但对最近邻格点不成立：
翻转两相邻自旋后的中间能差是

```text
dE_ij = dE_i + dE_j + 4 J s_i s_j,
```

必须显式求和 `i,i,j,j` 的六种有序路径。漏项从 `O(J^2)` 开始，因此旧记录中
`T*≈0.3094`、旧 `a4` 表和“与 T=.3 小场自洽”的解释全部撤回。修正后的有限链
四阶结果与通用 Dyson 路径枚举逐点一致，无限链结果与 `N=12` 收敛一致；稠密
配分函数展开另核到六阶。

## 方法与复现

- `ft_tc_quartic.py`：无限经典链 `2x2` 转移矩阵平均；最近邻双翻使用完整六路径核。
- `ft_tc_landau_paths.py`：枚举二、四、六阶所有回返路径。每条路径的虚时间积分为
  `F_m(d_0,...,d_m)=(-1)^m[d_0,...,d_m]exp(-beta x)`；重节点用 60 位
  `Decimal` 合流差商。六阶回返类型为 `6`、`4+2`、`2+2+2`。
- `ft_tc_tricritical_validate.py`：先对无限链 `a4(T)=0` 二分求根，再在该温度计算
  周期环 `N=6,8,10,12` 的精确路径系数。
- `ft_tc_thermal_threshold.py`：周期 ED `N=8,10,12` 与开链 NLCE `L=10,11,12`
  计算 `g_equal^2=h^2/[16(f(0)-f(h))]`。
- `ft_tc_transfer.py`：无限空间 Suzuki--Trotter 转移矩阵 `M=12,16,18,20`；表中
  热力学值分别用末 3/4 个点对 `1/M^2` 作二次截距。两个拟合窗口的一致性是
  数值诊断，不是严格误差界。

## 1. `a6(T*)` 验收

无限链修正四阶系数从 `[.25,.27]` 的异号端点二分得到

```text
T* = 0.257263616274686
a4_infinite(T*) = 2.25e-15
final bracket width = 7.27e-14
a2_infinite(T*) = -0.261585696042842
g_local(T*) = 0.488802043100057
```

精确有限环路径给出：

| `N` | `a4_N(T*)` | `a6_N(T*)` | `c4_N` in `g_equal-g_local≈c4 h^4` |
| ---: | ---: | ---: | ---: |
| 6 | `3.6082582e-4` | `0.0371731150` | `0.0347310553` |
| 8 | `5.9721334e-5` | `0.0374354871` | `0.0349761911` |
| 10 | `9.8511911e-6` | `0.0374869052` | `0.0350242313` |
| 12 | `1.6236845e-6` | `0.0374967195` | `0.0350334008` |

其中 `c4_N=g_local a6_N/[2(-a2_infinite)]`。`a6` 全部为正，`N=10→12`
只变 `9.81e-6`；因此 `a6(T*)>0` 通过本轮有限尺寸验收。尚未给出 `a6` 的解析
无限链闭式，故数值 `0.03750` 保留有限环收敛限定。

## 2. `T*` 处的小场下确界收敛

| `h` | `c4_(N12) h^4` | 转移矩阵末 3 点 | 转移矩阵末 4 点 | 周期 ED `N=12` |
| ---: | ---: | ---: | ---: | ---: |
| .025 | `+1.3685e-8` | `+1.3035e-8` | `+1.2143e-8` | `+3.8662e-7` |
| .05 | `+2.1896e-7` | `+2.1812e-7` | `+2.1726e-7` | `+5.9458e-7` |
| .10 | `+3.5033e-6` | `+3.4923e-6` | `+3.4914e-6` | `+3.8800e-6` |

表中后三列都是 `g_equal-g_local`。转移矩阵不仅保持正号，而且从 `.025` 到 `.1`
满足预言的 `h^4` 标度；周期 ED 的正有限尺寸偏差随 `N=8→10→12` 快速下降并趋向
同一值。NLCE `L=10–12` 原序列在极小 `h` 因近等自由能相减而慢收敛，Aitken 值在
`h=.05,.1,.2` 分别给约 `1.43e-7,3.47e-6,5.53e-5`，仅作辅助交叉；`h=.025`
的 Aitken 值轻微越过零，不作为符号裁决。

## 4. 有限搜索域检查

在 `T*` 有 `inf_(h>0) g_equal≤lim_(h→0)g_equal=g_local`，再结合
`g_equal²≥h/8`，任何全局最低都只可能位于
`h≤8g_local²=1.9114195`。粗扫覆盖 `.025≤h≤1.92`：小场最低在采样左端，
`h=.3` 已高于 `g_local` `2.78e-4`，随后 `.4,.6,...,1.92` 的差依次增至
`8.50e-4,3.90e-3,...,9.77e-2`，未见远场更低分支。这个离散扫描排除了宽的
遗漏分支，但不能排除网格间极窄极小；完整相图仍需连续全驻点搜索。

## 判定与边界

- **通过**：修正后的 `a4=0`、收敛的正 `a6`、`T*` 处从上方按 `h^4` 趋近
  `g_local`，以及邻域两侧有限场/零场下确界的符号切换，形成三条相互独立且
  定量一致的证据。
- **允许升级的表述**：`J=-.2,Delta=.2` 截面存在“数值强支持的热三临界候选”
  `(T*,g*)≈(.2572636,.4888020)`；不再只称“局部必要条件迹象”。
- **仍不允许的表述**：已证明热力学热三临界点、已完成相图、首次发现或投稿级
  新拓扑。剩余缺口是连续全域驻点/极窄分支排除、近等能误差的系统预算、多
  `Delta/J` 轨迹和文献访问缺口。
