# FT-TC 重入一级窄袋的全局预检（2026-11-23）

本轮检验[双根局部轨迹](../2026-11-23-ft-tc-trajectory/README.md)是否落实为全局
`g_equal` 结构。模型固定为 `J=-0.2, omega=1`，选择
`Delta=.4001,.4002,.40024`；每个截面自动定位上下两个 `a4(T)=0` 根，并在
下根外、`a4` 最负处和上根外取温度探针。

结论分级如下：

- `Delta=.4001`：ED 与 NLCE 可分辨 Landau 预言的小场负深度，且 `N=8,10`
  在 `0.03<=h<=h_max≈2.40` 未见远场内点极小；这是重入一级窄袋**至少一段**的
  全局数值支持。
- `Delta=.4002`：ED/NLCE 同号但信号仅约为经验方法差的 `1.42` 倍，属边缘证据。
- `Delta=.40024`：ED 与 NLCE 异号，当前双精度有限链路线不能裁决。
- Suzuki–Trotter 转移外推在这些极小场的窗口漂移约 `3.9e-6`，比目标信号大
  `10^3–10^5` 倍，不能用来裁决窄袋端点。

因此不能把局部切触端点 `(.4002585,.1255994)` 升级为全局相界端点；当前允许的
说法是“`.4001` 截面获得全局数值支持，向端点靠近后分辨率依次变为边缘和不足”。

## 方法与复现

预检驱动：[`ft_tc_reentrant_validate.py`](../../../code/src/ft_tc_reentrant_validate.py)。
零场周期 ED 已改用对角能量直接求配分和，避免把 `h=0` 的对角矩阵重复稠密
对角化；非零场算法和数值定义不变。

```powershell
& 'D:\codex\quantum-optics-env\python.exe' code/src/ft_tc_reentrant_validate.py `
  --J -0.2 --Delta 0.4001 0.4002 0.40024 --omega 1 `
  --T-range 0.08 0.18 --root-points 501 --temperature-floor 0.1 `
  --a6-N 8 10 12 `
  --output results/runs/2026-11-23-ft-tc-reentrant/reentrant-preflight.json

& 'D:\codex\quantum-optics-env\python.exe' code/src/ft_tc_reentrant_validate.py `
  --J -0.2 --Delta 0.4001 0.4002 0.40024 --omega 1 `
  --direct-crosscheck `
  --reuse-preflight results/runs/2026-11-23-ft-tc-reentrant/reentrant-preflight.json `
  --output results/runs/2026-11-23-ft-tc-reentrant/direct-crosscheck-all.json
```

远场搜索对每个截面的三个温度分别运行
[`ft_tc_global_stationary.py`](../../../code/src/ft_tc_global_stationary.py)：
`N=8`、160 个对数均匀点、`h_min=.03`，上界取严格的
`h_max=8g_local^2/omega`；`.4001` 另以 `N=10` 完整复核。具体命令参数保存在
`remote-scan-*.json`。所有 JSON 均保存确定性 `seed=null`、耗时和直接依赖源码的
SHA-256；本轮结束时哈希与工作树源码一致。

`.4001` 的 ED `N=8,10,12` 依次为
`.5477098330541,.5477098330667,.5477098330828`，NLCE 与 `N=12` 只差

约 `−3.30e-6`，末三/末四窗口差约 `3.91e-6`，故单独列为失效诊断，不与
ED+NLCE 的小场分辨率混合解释。

## 远场极小排除

九个 `N=8` 扫描在 `h>=.03` 均无内点极小，网格最低都落在左端且高于
`g_local`。`.4001` 的 `N=10` 复核为：

| `T` | 区域 | `g_equal(.03)-g_local` | 内点极小 |
| ---: | --- | ---: | ---: |
| .1000000 | 下根外 | +1.0336e-8 | 0 |
| .1256208 | 双根内 | +9.2186e-10 | 0 |
| .1453703 | 上根外 | +2.6239e-8 | 0 |

双根内的预测最低位于 `h*=.02016<.03`，已由上节直接交叉；从 `.03` 到严格
上界约 `2.40` 未发现更低的远场分支。离散扫描仍不能排除任意窄的未采样极小。

## 判定边界与下一步

- 允许：称 `.4001` 为“局部 Landau 信号、ED/NLCE 小场值和有界远场扫描共同支持
  的重入一级候选截面”。
- 不允许：把全部 `.4<Delta<Delta_end` 或切触端点称为已验证的全局相界。
- 最经济的后续路线不是继续加密双精度 ED，而是二选一：把论文主张收窄到已分辨
  区域；或为端点邻域建立能稳定处理 `1e-10–1e-11` 深度的高精度/张量网络方法。
