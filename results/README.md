- `runs/`：每次运行的参数、随机种子、代码版本、日志和原始输出；实际输出默认被 Git 忽略。
- `figures/`：经核对、准备在论文中引用的图；每张图需记录生成代码和输入。

## 一个运行中保存什么

```text
results/runs/<运行编号>/
  params.json       实际参数、模型版本、扫描方式与容差
  environment.txt   命令、依赖、硬件、代码版本与运行时间
  summary.json      成功/失败、残差、观测量与验证状态
  output.npz        数值原始输出（格式按任务选择）
  run.log           运行过程、警告与失败原因
  plots/            尚未验收的探索图
```

这是计划格式，尚未创建示例结果。详细字段见[路线第 3 节](../project/roadmap.md)。小型输入配置另存 `code/configs/` 并提交 Git；这里保存的是该次实际运行快照。跨运行汇总放 `data/processed/`，在本页记录输入运行编号和生成程序。

最终图通过截断、尺寸及适用极限检查后进入 `figures/`，图源与数据仍保留原位置。结果解释写入 `theory/derivations.md` 或 LaTeX 笔记；任务是否完成写入 `project/progress.md`。本页负责让每个结果找到来源，不重复全部推导和进度。
