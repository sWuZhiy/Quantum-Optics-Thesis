# 理论与推导

本目录保存本项目实际使用的模型、公式与数值方法。每份文档记录起始哈密顿量、参数、
近似、边界条件，以及与文献公式的对应关系；区分文献结果、作者解释与本项目推导，
未核对的步骤标“待核”。

| 文件 | 内容 |
| --- | --- |
| [model.md](model.md) | 哈密顿量与符号、热力学自洽泛函、等能判据与有限搜索上界、正常态局部阈值、二/四/六阶 Landau 系数（含近邻双翻修正）、热三临界候选 |
| [zero-t-baselines.md](zero-t-baselines.md) | 已发表零温一级/连续/三临界条件与 AFM 共存内点的复现校准 |
| [numerics.md](numerics.md) | 全部求解器的方法清单、参数与误差边界 |
