# FT-TC 零温 Z2 校准：精确极限与已知铁磁三临界条件

更新：2026-11-22。本文是**平衡有效哈密顿量**的已发表结果复现，不是新相或投稿贡献。统一模型、单位和热力学自洽适用范围见 [model.md](model.md)。取 `ℏ=k_B=1`、`s=σ/2`、`J<0` 为铁磁、`ω>0`：

```text
H_spin(h) = J Σ_i σ_i^z σ_(i+1)^z + (Δ/2) Σ_i σ_i^z + (h/2) Σ_i σ_i^x,
h=4gφ,       Φ_0(φ)=ωφ²+e_spin(0,4gφ),       0≤φ≤g/ω.
```

这个无限链自洽泛函用于单模集体耦合模型的单位点基态能，不等于有限 `N` 全光子模型的逐态对角化。`φ=0` 处的二次系数只检验局部稳定性；一级跃迁还须比较整个允许区间的全局能量。

## 1. `Δ=0`：精确横场 Ising 链及一级等能点

令 `K=−J>0`、`Γ=|h|/2`。Jordan–Wigner 可积极限给出无限链基态能密度

```text
e_spin(0,h)=−(1/π)∫₀^π √[K²+Γ²−2KΓ cos(k)] dk,    e_spin(0,0)=−K=J.
```

在给定非零 `h` 时，让 `ωφ²+e_spin(0,h)=J` 且 `φ=h/(4g)`，得到该侧分支与正常态等能所需的耦合

```text
g_equal(h)² = ω h² / {16 [J−e_spin(0,h)]},
g_c = min_(h>0) g_equal(h).
```

第二式是全局比较：只有取所有可能的横场后的最小值，才给出一级边界。数值用中点动量积分、`x=h/(2K)∈[0.05,8]` 粗筛和驻点方程二分细化；搜索区间是本次数值实现的边界，并非解析唯一性证明。侧分支驻点残差与积分点数收敛另列在[运行记录](../../results/runs/2026-11-22-ft-tc-z/README.md)。

| `J,ω,Δ` | `g_c`（全局等能） | `h_c`（本项目 `h`） | `φ_c` | 正常态局部失稳 `g_local` |
| --- | ---: | ---: | ---: | ---: |
| `−0.2,1,0` | `0.40904366821157` | `0.58099648120` | `0.35509441066` | `0.44721359550` |
| `−0.3,1,0` | `0.50097413481733` | `0.87149472180` | `0.43490005832` | `0.54772255751` |

**原文对照。** [Koziol（2026，arXiv:2605.27484v2）](https://arxiv.org/pdf/2605.27484)第 5 页图 3 固定 `J_K/ω=0.2`，同页 §VI 报 `ε=0` 的 `g_c/ω=0.4090436682`；其式 (1) 的 `g_K` 与本项目 `g` 相同，`J_K=−J`，而其链横场系数是本项目 `h/2`。我们的 `0.40904366821157` 与该数值吻合。按 [Hörmann（2026，arXiv:2606.26081v1）](https://arxiv.org/html/2606.26081v1)式 (18)、表 1，`g_H=2g`、`λ_H=2g²/ω`；所以此点 `λ_H/|J|=1.673167225`，也吻合其 §V.1、图 6 报告的约 `1.673`。两种文献的 `g` 不可直接混用。

## 2. `Δ>0`：零温二次、四次系数和三临界比值

将 [Koziol（2026）式 (1)、(10)–(14)](https://arxiv.org/html/2605.27484) 的 `ε_K=Δ/2`、`J_K=−J=K`、`h_K=h/2` 代入，记 `A=Δ/2−2J`、`B=Δ/2−J`，则在极化铁磁正常态附近

```text
e_spin(0,h)=J−Δ/2 − h²/(8A) + (Δ/2+J) h⁴/(128 A³ B) + O(h⁶),
Φ_0(φ)=Φ_0(0) + [ω−2g²/A] φ²
                   + [2g⁴(Δ/2+J)/(A³B)] φ⁴ + O(φ⁶).
```

因此 `g_local²=ω(Δ−4J)/4`；四次系数在 `Δ=−2J` 变号。该处二次系数同时为零时，零温解析三临界点为 `g_tc²=−3ωJ/2`。由 [Koziol（2026）附录 C 式 (29)–(33)](https://arxiv.org/html/2605.27484) 换算，该点的六次系数为 `7ω³/(180J²)>0`，维持局部稳定。例如 `J=−0.2` 时 `(Δ_tc,g_tc)=(0.4,√0.3)`、六次系数 `35/36≈0.972222`；其连续侧 `Δ=0.6` 的解析边界是 `g_c=√0.35≈0.5916079783`，对应 [Langheld 等（2025）图 3(c)](https://arxiv.org/html/2409.15082) 的 `ε=0.3,Jd=−0.2`。项目有限温试算常用 `J=−0.3` 时的三临界校准为 `(0.6,√0.45)`。这些是**局部 Landau 校准**；在 `Δ<−2J`，负四次项提示一级跃迁先于正常态局部失稳，不能把 `g_local` 报作真实一级边界。`Δ=0` 须用上一节的精确全局比较。

## 3. 反铁磁共存窗口的有限链内点

[Langheld 等（2025）原始数据集，DOI 10.5281/zenodo.15774230](https://zenodo.org/records/15774230) 的 `Antiferro_chain_ANAS.csv` 与 `Antiferro_chain_ASPS.csv` 在 `J=+0.2,g=0.26,ω=1` 报 `ε∈(0.325424,0.336539)` 的 AFM–超辐射共存窗口。按该文式 (1) 到本项目的映射 `ε=Δ/2`，选中间点 `ε=0.33125`，即 `Δ=0.6625`。这是**作者报告的零温窗口**；我们只检验内部一个点。

在此点，允许横场为 `0≤h≤4g²/ω=0.2704`。本项目 `N=16` 周期链的 54 点全区间网格在 `h≈0.07010` 取得最低采样能量，较 `h=0` 低约 `1.5668×10⁻⁴`；`N=12,16,18` 的局部细网格在 `h=0.07` 给 `φ²≈0.0045303` 和 `m_s²=⟨[Σ_i(-1)^iσ_i^z/N]²⟩≈0.8962,0.8938,0.8930`。作者原始 `L=1024,β=512` QMC 行在同参数报 `n_ph≈0.0045076`、`mag2≈0.888634`。两类计算的物理量定义与参数相对应，有限 `N`、完整光子量子涨落及温度处理不同，不能把数值接近当作严谨同一热力学极限误差界。原始行、运行参数和残差见[运行记录](../../results/runs/2026-11-22-ft-tc-z/README.md)。

## 4. 当前验证边界

精确可积点和上述 Landau 归一化已复算，并用 `N≤18` 的矩阵自由 Lanczos 检查了一个非零纵场铁磁一级侧、一个连续侧和一个反铁磁共存内点；但**完整**铁磁/反铁磁零温相界与受控无限链磁序外推尚未重现。`code/src/ft_tc_zero_t.py` 只处理可积积分及局部系数，`code/src/ft_tc_ground_state.py` 给有限链基态能与可选交错磁序平方，`code/src/ft_tc_zero_t_scan.py` 扫横场和腔位移。后续还需在边界邻域做全局极小和尺寸/团簇收敛。历史有限温 `T=.1` 的候选侧分支交叉不是零温边界，也不由本页的校准点证明。
