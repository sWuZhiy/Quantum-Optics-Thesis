# FT-TC P0 的统一模型与解析校准

更新：2026-11-23。本文定义用于**平衡有效哈密顿量**数值预审的符号；它不声称任意真实无驱动腔器件都能实现平衡超辐射相变，也不描述开放系统稳态。取 `ℏ=k_B=1`、周期一维链、`s_i^α=σ_i^α/2`、`ω>0`，暂不加入从属二次光场项。

```text
H_N = ω a†a + Δ Σ_i s_i^z + 4J Σ_i s_i^z s_(i+1)^z
      + (2g/√N)(a+a†) Σ_i s_i^x ,
H_spin(h_x) = J Σ_i σ_i^z σ_(i+1)^z + (Δ/2)Σ_i σ_i^z
              + (h_x/2)Σ_i σ_i^x ,
h_x = 4gφ,   φ = Re⟨a⟩/√N.
```

`J<0` 为铁磁、`J>0` 为反铁磁，`Δ>0` 可通过全局 `z` 翻转选定。与 [Koziol（2026）式 (1)](https://arxiv.org/html/2605.27484) 的 `−εΣσ^z−J_KΣσ^zσ^z + g_K(a+a†)Σσ^x/√N` 对照，整体 `z` 翻转后有 `ε=Δ/2`、`J_K=−J>0`、`g_K=g`。因此他的零温三临界比值 `ε=J_K` 对应本项目 `Δ=−2J`；这只是**比值基线**，不是本项目发现。

在单模集体耦合、`N→∞` 的热力学自洽处理下，定义无限链单位点物质自由能和候选腔位移泛函

```text
f_spin(T,h_x) = −lim_(N→∞)(T/N) log Tr exp[−H_spin(h_x)/T],
Φ_T(φ) = ωφ² + f_spin(T,4gφ),       f(T)=min_(φ∈R) Φ_T(φ).
```

这个处理继承了集体耦合的热力学自洽原理；有限 `N` 的完整光子—自旋配分函数不能直接用 `Φ_T` 代替。`Φ_T` 为偶函数，且 `|∂f_spin/∂h_x|=|⟨s_i^x⟩|≤1/2`，故在 `φ≥g/ω` 时 `dΦ_T/dφ≥2ωφ−2g≥0`。所有全局极小值均可在 `[0,g/ω]` 搜索；一级边界必须比较**全部**极小值的自由能，不由正常态局部曲率单独决定。

## 正常态第一次失去全局优势的等能判据

令 `h=4gφ≥0`、`A_T(h)=f_spin(T,0)−f_spin(T,h)`。对固定 `T,J,Δ,ω>0` 和 `g>0`，直接从上面的泛函得到

```text
Φ_T[h/(4g)]−Φ_T(0) = ωh²/(16g²)−A_T(h),
g_equal²(T,h) = ωh²/[16 A_T(h)]                 (h>0, A_T(h)>0),
g_onset(T) = inf_(h>0) g_equal(T,h).
```

这是对**正常态与任意有限光场态的全局自由能比较**作变量替换；不是新的物理机制或独立发表主张。若下确界在有限 `h` 取得，该点给正常态与一个有限位移态等能的一级跃迁**候选**；还须以收敛的无限链 `f_spin` 搜索全部驻点，并检查被比较的有限位移确为全局极小。若最小值只在 `h→0` 取得，它退化为下面的正常态局部阈值。这个判据只找正常态首次失去全局优势的耦合，不给两个非零位移相之间的边界，也不单独证明热三临界点。有限链 ED 或有限阶 NLCE 代入此式只能用于预研；不能直接把其极小值称为热力学相界。

`f_spin(T,h)` 因全局 `z` 翻转对 `h` 为偶函数，作为线性场的平衡自由能又是凹函数；所以 `A_T(h)≥0`。从 `|∂f_spin/∂h|≤1/2` 还得 `A_T(h)≤h/2`，进而 `g_equal²(T,h)≥ωh/8`。一旦在某个参考场 `h_ref` 求得有限候选 `g_ref=g_equal(h_ref)`，**所有 `h>8g_ref²/ω` 都不可能给更小的等能耦合**。这给第一次正常态失稳的连续 `h` 搜索一个可证明的有限上界，仍须在此区间内做全局而非单个预选局部极小搜索。例如 `T=.1,J=-.2,Δ=.2,ω=1` 的已查候选 `g_ref≈.49547` 给上界约 `1.964`；[本轮延长网格](../../results/runs/2026-11-22-ft-tc-t-entry/README.md)抽样到 `h=2`，但有限网格不证明区间内无其他狭窄极小。

## 正常态的精确有限温局部阈值

`φ=h_x=0` 时物质链退化为一维经典 Ising 链。令 `β=1/T`，`σ_i^z=s=±1`。相邻自旋的转移矩阵与最大本征值为

```text
K_(a,b)=exp{−β[Jab+Δ(a+b)/4]},    λ=max eig(K),
f_spin(T,0)=−T log λ.
```

若 `v` 是归一化的最大本征矢，则无限链连续三自旋概率为 `P(a,s,b)=v_a K_(a,s)K_(s,b)v_b/λ²`。翻转中央自旋的能量差为 `δE(a,s,b)=−s[Δ+2J(a+b)]`。由 `h_xΣσ^x/2` 的零场 Kubo 二阶响应，定义

```text
Q(T,J,Δ) = Σ_(a,s,b) P(a,s,b) [1−exp(−β δE)]/δE,
χ_x = −∂⟨s_i^x⟩/∂h_x|_0 = Q/4,
Φ_T(φ) = Φ_T(0) + [ω−2g²Q]φ² + O(φ⁴),
g_local(T) = sqrt[ω/(2Q)].
```

当 `δE=0`，方括号取极限 `β`。`g_local` 仅是正常态**局部失稳**阈值；一级跃迁可在 `g<g_local` 发生。该有限温三自旋概率求和及阈值是本项目从上述哈密顿量推得的解析校准，不是新颖性主张；实现见 [`code/src/ft_tc_normal_curvature.py`](../../code/src/ft_tc_normal_curvature.py)。`J=0` 时恢复 `g_local²=ωΔ/[4 tanh(Δ/(2T))]`。在 `J<0,Δ>0,T→0` 的极化正常态，`g_local²→ω(Δ−4J)/4`；按前述映射，它等同于 [Koziol（2026）式 (10)–(14)](https://arxiv.org/html/2605.27484) 的零温二次系数消失条件。

`J=−0.3,Δ=0.3,ω=1` 时零温局部阈值为 `sqrt(0.375)=0.6123724357`；有限温 `T=0.1` 的精确值 `0.6123718932`。本项目预筛的侧分支候选交叉 `g≈0.6069` 位于局部阈值以下，与一级边界所需的正常态局部稳定性一致；这**不是**全局一级线的证明。原始数值及收敛边界见[方法备忘](../../docs/archive/method-feasibility.md)和[运行记录](../../results/runs/2026-11-21-ft-tc-p0/README.md)。

已发表零温一级/连续/三临界与反铁磁共存内点的后续校准，统一记录在[零温基线](zero-t-baselines.md)与[Z2 运行](../../results/runs/2026-11-22-ft-tc-z/README.md)；这些结果不改变上面有限温候选交叉的证据级别。

## 有限温 Landau 系数：相邻双翻修正与六阶路径

在**固定 `T>0` 且有限周期链 `N`**，令 `H_spin(h)=H_0+hV`、
`V=(1/2)Σ_i σ_i^x`、`β=1/T`，并写

```text
f_N(T,h) = f_N(T,0) + a_(2,N) h² + a_(4,N) h⁴ + a_(6,N) h⁶ + O(h⁸),
Z_N(h)  = Z_0 + h² Z_2 + h⁴ Z_4 + h⁶ Z_6 + O(h⁸).
```

对零横场构型 `s`，记翻转集合 `X` 后的相对能量
`dE_X=E(s xor X)-E(s)`。一条含 `m` 次翻转、最终回到 `s` 的有序路径，其
虚时间积分为 Hermite 合流差商

```text
F_m(d_0,...,d_m) = (-1)^m [d_0,...,d_m] exp(-βx),
d_0=d_m=0.
```

因此 `Z_m/Z_0` 是所有回返路径的经典零场热平均再乘 `2^{-m}`。六阶只需枚举
站点重数 `6`、`4+2`、`2+2+2`；系数由对数配分函数直接给出

```text
a_2 = -(T/N) z_2,
a_4 = -(T/N) (z_4 - z_2²/2),
a_6 = -(T/N) (z_6 - z_2 z_4 + z_2³/3),     z_m=Z_m/Z_0.
```

四阶可进一步化简。单站四翻核记为 `I(dE_i,dE_i)`，不相邻两站各翻两次时
确实因子化为 `B1(dE_i)B1(dE_j)`；但最近邻不因子化，因为双翻中间态满足

```text
dE_ij = dE_i + dE_j + 4 J s_i s_j.
```

必须对 `i,i,j,j` 的六种排列逐条使用 `F_4`。若 `K_ij` 表示该六路径之和，则

```text
Z_2/Z_0 = (1/4) <sum_i B1(dE_i)>,
Z_4/Z_0 = (1/16) < sum_i I(dE_i,dE_i)
                       + sum_(i<j) B1(dE_i)B1(dE_j)
                       + sum_(<ij>) [K_ij-B1(dE_i)B1(dE_j)] >.
```

这项最近邻修正从 `O(J²)` 开始。2026-11-22 的旧实现漏掉它，导致
`T*≈.3094` 的旧结论错误；旧运行已明确标为[撤回](../../results/runs/2026-11-22-ft-tc-quartic/README.md)，
原始文件仅为审计保留。修正实现见 [`ft_tc_quartic.py`](../../code/src/ft_tc_quartic.py)，
不作任何因子化的通用二至六阶路径实现见
[`ft_tc_landau_paths.py`](../../code/src/ft_tc_landau_paths.py)。验证包括 `J=0` 的
`a_2/a_4/a_6` 闭式、通用路径与专用四阶代码逐点一致、有限链趋向无限链，以及
稠密 ED 配分函数的六阶截断核对。

对 `J=-.2,Delta=.2,omega=1`，修正后的无限链四阶根为

```text
T* = 0.257263616274686,
a2(T*) = -0.261585696042842,
g_local(T*) = 0.488802043100057.
```

精确有限环路径给 `a6(T*)=0.0371731,0.0374355,0.0374869,0.0374967`
（`N=6,8,10,12`），末两尺寸差 `9.81e-6`，稳定为正。候选点附近

```text
g_equal²(h) = omega/[16(-a2-a4 h²-a6 h⁴+...)],
g_equal(T*,h)-g_local = g_local*a6/[2(-a2)] h⁴ + O(h⁶),
```

其 `N=12` 预测系数为 `0.0350334`。无限空间转移矩阵在
`h=.025,.05,.1` 给出的差 `1.2e-8,2.17e-7,3.49e-6` 与该 `h⁴` 标度一致；
`T=.25<T*` 时小场差为负，而 `T=.265>T*` 时为正。加上覆盖可证明有限搜索上界
的 ED 粗扫，这允许把该点升级为**数值强支持的热三临界候选**，但离散扫描仍不能
排除极窄的远场极小，故不称已证明热三临界点或完整相图。完整数据、误差边界和
复现命令见[2026-11-23 验收记录](../../results/runs/2026-11-23-ft-tc-landau/README.md)。
