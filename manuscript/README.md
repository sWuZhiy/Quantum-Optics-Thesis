# 论文素材

本目录是论文写作素材，分两层：

| 子目录 | 内容 |
| --- | --- |
| [`theory/`](theory/) | 模型、推导、数值方法与误差边界（[README](theory/README.md)） |
| [`notes/`](notes/) | 阶段性研究汇总：LaTeX 论文文本，按阶段整合、编译成 PDF 供审阅与汇报（[README](notes/README.md)） |

引用统一来自 [`literature/references.bib`](../literature/references.bib)。方向、导师及学校
格式要求确认后，再把阶段汇总迁移到 APS REVTeX/PRL 风格的正式论文源文件；编译中间文件
（`build/`、`.aux/.log/...`）不提交 Git。
