## 1. 候选问题的精确定义

暂以 `ℏ=k_B=1`、`s_i^α=σ_i^α/2`，考虑一维周期链热力学极限：

```text
H0 = ω a†a + Δ Σ_i s_i^z + 4J Σ_i s_i^z s_{i+1}^z
     + (2g/√N)(a+a†) Σ_i s_i^x .
```

核心候选不是“加入反压缩”，而是：在与 Langheld–Hörmann–Schmidt、Leibig 等零温模型相同的 `zz` 交换、`z` 纵场和 `x` 腔耦合轴向下，确定零温正常—超辐射一级/二级边界及三临界点在 `T>0` 如何延伸，是否形成三临界线、临界终点或其他可由全局自由能区分的热结构。

可选从属项

```text
Hq = [D(g)-ξ](a+a†)²
```

只用于受约束控制路径和原光子观测量。稳定域 `ω+4[D(g)-ξ]>0` 内，`Hq` 可被精确压缩变换吸收，不能作为核心新机制。

## 3. 当前可以说与不能说的内容

可以说：

- 已有直接零温工作建立了候选轴向下的一级/二级边界、三临界机制和反铁磁共存结构。
- Gammelmark–Mølmer 已证明量子 Ising–腔系统的有限温一/二阶超辐射转变不是空白，但其自旋轴向和可积结构与候选 `H0` 不同。
- 当前定向核查尚未找到一篇同时满足“候选 `zz/z/x` 哈密顿量、非零纵场 + 完整平衡有限温全局相图 + 零温三临界结构热延伸”的论文；Rao（2025）和 Granet（2023）已覆盖不同轴向的量子链热转变，显著收窄宽泛说法。

不能说：

- “首次研究有限温 Dicke–Ising”或“此前无人研究有限温超辐射三临界”。
- “Hörmann 把它列为展望，所以一定可发表”。展望只说明其正文未做，不证明所有文献均未做。
- “加入 `D-ξ` 会产生新的热相图机制”。稳定域内它先是精确参数重标定。
- 用小系统热 ED 的平滑峰值宣称热相变或三临界线。

## 4. 缺口假设与最便宜的反证

暂定缺口假设 `G1`：

> 在 `H0` 的 `zz/z/x` 轴向和热力学极限下，零温铁磁量子三临界点的有限温延伸尚未被完整给出；其全局自由能分支和热终点结构相对 Gammelmark–Mølmer 的可积轴向存在非平凡差异。

最便宜的反证按优先级排列：

1. 找到一篇相同 `H0`、相同热平衡对象且已给完整 `T>0` 一级/二级边界的论文。
2. 证明候选有限温自由能可经整体自旋旋转或精确变量替换完全化为 Gammelmark–Mølmer 的结果，且目标区域没有额外物理约束。
3. 证明在可获得资源内只能得到小系统交叉，无法控制热力学极限或全局一级边界。
4. 证明有限温延伸只产生平凡的零温线平滑终止，没有可区分、可验证的新预测；此时可作为毕业设计基准，但不满足投稿潜力目标。
