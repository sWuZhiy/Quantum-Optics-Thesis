# Otake 与 Bamba（2026）：腔耦合 Ising 链的有限温度精确结果

- **出处**：*Physical Review Research* **8**, 023150 (2026)，[DOI](https://doi.org/10.1103/fxml-nv46)；引用键 `Otake2026FiniteT`。
- **研究对象**：与单模腔耦合的一维**经典** Ising 链，研究严格热平衡的有限温度相变。
- **方法与结果**：将腔介导的全连接相互作用用自洽/辅助场处理，再用一维经典 Ising 链的精确解得到磁化、腔场与临界温度；尽管纯短程一维经典链没有有限温度相变，腔耦合体系可以有。
- **A² 处理**：论文主模型未将独立 $D(a+a^\dagger)^2$ 或反压缩 $\xi$ 作为控制量；亦未包含量子自旋涨落。
- **与毕设关系**：有限温度相变不是空白课题。若研究量子 Ising + A² + 反压缩，应明确超过其经典链结果的温度效应和方法边界。
- **核读状态**：APS 开放正文的摘要、模型、结论及附录 C–D 结构已核；具体临界温度公式待独立推导。
