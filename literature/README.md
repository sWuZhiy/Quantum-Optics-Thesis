## 本题必读的外部先例

- [Langheld、Hörmann、Schmidt，Dicke–Ising QMC，2025](https://arxiv.org/html/2409.15082)：正文相图，尤其补充材料 §IV 的 `A²` 映射和图 S9 可达区域。

- [Nataf、Ciuti，腔 QED 禁戒定理与电路反例，2010](https://www.nature.com/articles/ncomms1069)：核对“平衡”“超越禁戒”的适用前提。
