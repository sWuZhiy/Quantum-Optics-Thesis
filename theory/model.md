# FT-TC P0 的统一模型与解析校准

更新：2026-11-21。本文定义用于**平衡有效哈密顿量**数值预审的符号；它不声称任意真实无驱动腔器件都能实现平衡超辐射相变，也不描述开放系统稳态。取 `ℏ=k_B=1`、周期一维链、`s_i^α=σ_i^α/2`、`ω>0`，暂不加入从属二次光场项。

```text
H_N = ω a†a + Δ Σ_i s_i^z + 4J Σ_i s_i^z s_(i+1)^z
      + (2g/√N)(a+a†) Σ_i s_i^x ,
H_spin(h_x) = J Σ_i σ_i^z σ_(i+1)^z + (Δ/2)Σ_i σ_i^z
              + (h_x/2)Σ_i σ_i^x ,
h_x = 4gφ,   φ = Re⟨a⟩/√N.
```

`J<0` 为铁磁、`J>0` 为反铁磁，`Δ>0` 可通过全局 `z` 翻转选定。与 [Koziol（2026）式 (1)](https://arxiv.org/html/2605.27484) 的 `−εΣσ^z−J_KΣσ^zσ^z + g_K(a+a†)Σσ^x/√N` 对照，整体 `z` 翻转后有 `ε=Δ/2`、`J_K=−J>0`、`g_K=g`。因此他的零温三临界比值 `ε=J_K` 对应本项目 `Δ=−2J`；这只是**比值基线**，不是本项目发现。

在单模集体耦合、`N→∞` 的热力学自洽处理下，定义无限链单位点物质自由能和候选腔位移泛函

```text
f_spin(T,h_x) = −lim_(N→∞)(T/N) log Tr exp[−H_spin(h_x)/T],
Φ_T(φ) = ωφ² + f_spin(T,4gφ),       f(T)=min_(φ∈R) Φ_T(φ).
```

这个处理继承了集体耦合的热力学自洽原理；有限 `N` 的完整光子—自旋配分函数不能直接用 `Φ_T` 代替。`Φ_T` 为偶函数，且 `|∂f_spin/∂h_x|=|⟨s_i^x⟩|≤1/2`，故在 `φ≥g/ω` 时 `dΦ_T/dφ≥2ωφ−2g≥0`。所有全局极小值均可在 `[0,g/ω]` 搜索；一级边界必须比较**全部**极小值的自由能，不由正常态局部曲率单独决定。

## 正常态的精确有限温局部阈值

`φ=h_x=0` 时物质链退化为一维经典 Ising 链。令 `β=1/T`，`σ_i^z=s=±1`。相邻自旋的转移矩阵与最大本征值为

```text
K_(a,b)=exp{−β[Jab+Δ(a+b)/4]},    λ=max eig(K),
f_spin(T,0)=−T log λ.
```

若 `v` 是归一化的最大本征矢，则无限链连续三自旋概率为 `P(a,s,b)=v_a K_(a,s)K_(s,b)v_b/λ²`。翻转中央自旋的能量差为 `δE(a,s,b)=−s[Δ+2J(a+b)]`。由 `h_xΣσ^x/2` 的零场 Kubo 二阶响应，定义

```text
Q(T,J,Δ) = Σ_(a,s,b) P(a,s,b) [1−exp(−β δE)]/δE,
χ_x = −∂⟨s_i^x⟩/∂h_x|_0 = Q/4,
Φ_T(φ) = Φ_T(0) + [ω−2g²Q]φ² + O(φ⁴),
g_local(T) = sqrt[ω/(2Q)].
```

当 `δE=0`，方括号取极限 `β`。`g_local` 仅是正常态**局部失稳**阈值；一级跃迁可在 `g<g_local` 发生。该有限温三自旋概率求和及阈值是本项目从上述哈密顿量推得的解析校准，不是新颖性主张；实现见 [`code/src/ft_tc_normal_curvature.py`](../code/src/ft_tc_normal_curvature.py)。`J=0` 时恢复 `g_local²=ωΔ/[4 tanh(Δ/(2T))]`。在 `J<0,Δ>0,T→0` 的极化正常态，`g_local²→ω(Δ−4J)/4`；按前述映射，它等同于 [Koziol（2026）式 (10)–(14)](https://arxiv.org/html/2605.27484) 的零温二次系数消失条件。

`J=−0.3,Δ=0.3,ω=1` 时零温局部阈值为 `sqrt(0.375)=0.6123724357`；有限温 `T=0.1` 的精确值 `0.6123718932`。本项目预筛的侧分支候选交叉 `g≈0.6069` 位于局部阈值以下，与一级边界所需的正常态局部稳定性一致；这**不是**全局一级线的证明。原始数值及收敛边界见[方法备忘](../project/method-feasibility.md)和[运行记录](../results/runs/2026-11-21-ft-tc-p0/README.md)。

已发表零温一级/连续/三临界与反铁磁共存内点的后续校准，统一记录在[零温基线](zero-t-baselines.md)与[Z2 运行](../results/runs/2026-11-22-ft-tc-z/README.md)；这些结果不改变上面有限温候选交叉的证据级别。
