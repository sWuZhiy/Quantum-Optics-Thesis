# 理论与推导

先建立模型和符号约定，再放详细推导。每份推导记录起始哈密顿量、参数、近似、边界条件，以及与文献公式的对应关系。

当前尚无独立模型文件和完整推导。下一批交付集中在两个文档，随研究推进追加章节：

| 计划文件 | 内容 | 对应任务 |
| --- | --- | --- |
| `model.md` | 哈密顿量与版本、单位与符号表、键计数、平台来源/假设、文献参数对照、两个基准定义 | A2–A5 |
| `derivations.md` | 稳定性、压缩变换与能量常数、观测量变换、解析极限；随后补自由能、自洽条件与边界判断 | B1–B6 |

每段推导区分文献公式和本项目推导，并附出处、核对极限与适用范围。尚未核对的步骤标“待核”；数值图表引用运行记录，不把程序输出当作解析证明。文献内容介绍仍集中在[统一文献综述](../literature/reading-list.md)，这里保存本项目实际使用的公式与约定。
