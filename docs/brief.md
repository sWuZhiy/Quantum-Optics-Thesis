# 项目简述

## 已确认

- 项目类型：量子光学毕业设计。
- 现有文献主题：超辐射相变及相关量子光学模型。
- 项目目标：在可完成毕业设计的基础上，优先争取形成具有投稿潜力的明确增量；“投稿潜力”是选题筛选标准，不是对成果或录用的预先承诺。
- 研究路线偏好：优先平衡态超辐射；若具体耗散机制具有更明确价值，可作为备选。准备阶段采用简单 LaTeX 笔记；方向确定且进入正式写作后再转 APS/PRL 风格模板。
- 已否定的核心主张：在静态单模、同一正交分量上把反压缩项加到含 `A²` 和自旋相互作用的模型中，**不会仅凭该加项产生新的平衡竞争机制**；稳定域内它可被精确压缩映射吸收。该结构只保留为解析基线、参数可达性和原光子观测量映射，不再作为投稿主线。
- 持续改进方式：活动主张、证据、反证条件和状态统一写入 [claims.md](claims.md)；被否定的主张退出当前路线，但在台账和[决策记录](decisions.md)中保留理由。

## 待确认

- 具体题名与最终主张边界：`FT-TC` 已满足导师接受的 Ising 题目范围，并通过毕设立题/定向 T 阶段的条件门槛；正式题名仍待学校格式和最终图景确定。投稿层面的“同模型热拓扑空白”仍是可反证假设，不能因定向检索未命中先例而写成已确认首次发现。
- `D(g)` 与 `ξ` 的定位：若 `FT-TC` 通过新颖性门槛，可作为受约束控制路径和原光子可观测量的从属问题；它们本身不构成核心创新。
- `CL-AF` 的定位：暂降为自由能、一级边界和程序验证的基准/备选，不投入完整投稿相图；已有混合短程—长程 Ising 先例显著限制其独立新颖性。
- 开放系统或其他非等价模型：耗散、不同正交分量、多模、时变泵浦或非高斯光子项均会改变问题。已有 Wang、Li、Chen（2026，arXiv:2602.09912）等耗散 Dicke–Ising 工作，因此任何转向都需重新查重和定义，不自动成为备选答案。
- 导师要求与可用资源：**题目范围已确认（2026-11-22）：只要有 Ising 相互作用即可，范围较广**；即当前 `FT-TC`（量子 Dicke–Ising 链有限温）满足题目要求，即使投稿级新颖性被证伪，也可按 Ising 相互作用相关题目完成毕设。具体计算资源仍未单独确认。
