好问题，这触及数值相变判定的核心。查完记录，文献大致分**两条路线**：一条绕开有限 N，一条用有限 N 外推。

## 1. 两条路线

**路线 A：热力学极限直接方法**——不碰有限 N，直接算 `N→∞`

| 文献 | 做法 |
|---|---|
| Gammelmark–Mølmer 2011 | 可积模型，Jordan–Wigner **精确解无限链** |
| Leibig 2026 | 自洽物质模型 + **NLCE**（数值连续簇展开本身就是无限链的逐阶逼近） |
| Otake–Bamba 2026 | 经典链**精确解** + 腔自洽 |
| 我们（部分） | NLCE、Suzuki–Trotter **无限空间**转移矩阵 |

这类方法的逻辑是：既然相变只在 `N→∞`，那就**用公式/算法直接算无限链**，不引入有限 N 这个"假象"。

**路线 B：有限尺寸标度（finite-size scaling，FSS）**——用有限 N/L 的结果外推

| 文献 | 做法 |
|---|---|
| Langheld 2025 | wormhole QMC 到 `L=1024`、`β=512`（已经很大，接近极限），再做外推 |
| Mendonça 2025/2026 | 光子变分态 + 自旋 DMRG，有限 `N`，看 `⟨n⟩/N ∝ N^(-α)` 的标度 |
| 我们（ED 部分） | `N≤12/14`，用 `N` 收敛检查 |

## 2. 关键难点：有限 N 下"没有"相变

这是理解的核心。在有限 `N` 的**量子**系统里，超辐射相变是**不存在的**——因为序参量（腔位移 `φ`）在有限 N 下**严格为零**：基态保持 `Z₂` 对称（`a→-a`），`⟨a⟩=0`。相变只在 `N→∞` 才作为极限出现。

所以文献"数值算超辐射"时，**看的不是序参量本身，而是序参量的涨落/标度**：

- 看 `⟨a†a⟩/N`（光子密度）或 `⟨φ²⟩` 随 `N` 怎么变；
- 若 `N→∞` 时 `⟨a†a⟩/N → 非零常数`，就是真正的超辐射相（宏观光子数）；
- 若 `⟨a†a⟩/N → 0`（比如按 `N^(-α)` 趋零），就没有真正的超辐射相，只是有限尺寸的"假亮"。

**Mendonça 的争议正是卡在这里**：他们报告 XXZ 中间区 `⟨n⟩/N ∝ N^(-α)`、`0<α<1`。如果这个标度是真实的渐近律，那 `N→∞` 时宏观光子密度趋零——**就没有超辐射相**，只是有限尺寸的缓慢交叉。但"这个标度是真实渐近行为，还是极小 `g`/有限 `N` 造成的长交叉"，原文没解决，这正是我们记录的 C08 备选课题（[专题预筛](literature/mendonca-followup-survey.md) §3A）。

## 3. 一级 vs 二级，有限 N 的表现不同

- **二级（连续）相变**：有限 N 下表现为**越来越尖锐的交叉**（crossover），磁化率/关联长度随 N "变高但不发散"。FSS 用标度假设把不同 N 的曲线塌缩到一条，外推出临界点和临界指数。
- **一级相变**：有限 N 下表现为**能级/自由能交叉**（level crossing）和序参量的**双峰分布**（两个亚稳态共存）。比二级更好判——交叉点随 N 收敛得很快。

我们的判据 `g_equal`（等能耦合）本质上就是一级跃迁的"自由能交叉"判据，所以它在有限 N 下比二级判据稳。

## 4. 回到我们：为什么要强调热力学极限

我们的处理其实是**路线 A 和 B 的混合**：

- **NLCE、无限空间转移矩阵** = 路线 A，直接算无限链，`a₂/a₄/a₆` 的零场系数甚至用**经典组合路径精确枚举**（这条路线上是精确的，不涉及有限 N）；
- **ED `N≤12/14`** = 路线 B，用来做有限尺寸收敛检查，不作为热力学结论的来源。

这正是 claims 里所有结论都停在"数值诊断级"的原因：**有限温 Dicke–Ising 的无限链 `f_spin(T,h)` 我们只有 NLCE/转移矩阵两种收敛方法，没有第三种独立的热力学极限方法（如 SSE/有限温 MPS）来钉死它**。文献（Leibig 等）在零温侧有 NLCE+DMRG 双重交叉，但有限温侧他们没有做——这是我们的机会，也是我们必须补的缺口。
