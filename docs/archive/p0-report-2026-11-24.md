## 3. 理论框架

### 3.1 模型与自由能泛函

取 `ℏ=k_B=1`、`s_i^α=σ_i^α/2`、周期链 `N` 位点、`J<0` 铁磁、`ω>0`：

```text
H_N = ω a†a + Δ Σ_i s_i^z + 4J Σ_i s_i^z s_{i+1}^z + (2g/√N)(a+a†) Σ_i s_i^x,
H_spin(h_x) = J Σ_i σ_i^z σ_{i+1}^z + (Δ/2) Σ_i σ_i^z + (h_x/2) Σ_i σ_i^x,
h_x = 4gφ,  φ = Re⟨a⟩/√N.
```

热力学自洽处理（继承单模集体耦合的鞍点原理；有限 `N` 的完整配分函数不能直接用
`Φ_T` 代替）给出候选腔位移泛函

```text
f_spin(T,h_x) = −lim_{N→∞} (T/N) log Tr exp[−H_spin(h_x)/T],
Φ_T(φ) = ω φ² + f_spin(T, 4gφ),   f(T) = min_φ Φ_T(φ).
```

`Φ_T` 为偶函数，`|∂f_spin/∂h_x| ≤ 1/2`，故全局极小只需在 `0 ≤ φ ≤ g/ω` 搜索；
一级边界必须比较全部极小值的自由能。

### 3.2 正常态等能判据与有限搜索上界

令 `h=4gφ≥0`、`A_T(h)=f_spin(T,0)−f_spin(T,h)`，正常态与任意有限场态的等能耦合为

```text
g_equal(h)² = ω h² / [16 A_T(h)]  (h>0, A_T(h)>0),
g_onset(T) = inf_{h>0} g_equal(T,h).
```

这是变量替换（`g` 换 `h`），不是新物理。由 `A_T(h)≤h/2` 得
`g_equal² ≥ ωh/8`，故找到任一参考 `g_ref` 后，比它更低的等能耦合只需在

```text
h ≤ 8 g_ref² / ω
```

的**严格有限域**内连续搜索。下确界在有限 `h` 取得 → 一级跃迁候选（还需全驻点与
全局验证）；只在 `h→0` 取得 → 退化为局部阈值 `g_local`。

### 3.3 正常态局部阈值（精确）

`h_x=0` 时物质链为经典 Ising 链，`2×2` 转移矩阵 `K(a,b)=exp{−β[Jab+Δ(a+b)/4]}`
的最大本征值 `λ` 给 `f_spin(T,0)=−T log λ`。三自旋概率
`P(a,s,b)=v_a K_{as}K_{sb}v_b/λ²`（`v` 为 Perron 本征矢），翻转中央自旋的能量差
`δE(a,s,b)=−s[Δ+2J(a+b)]`。零场 Kubo 二阶响应给

```text
Q(T,J,Δ) = Σ_(a,s,b) P(a,s,b) [1−exp(−β δE)]/δE,
χ_x = Q/4,  g_local(T)² = ω/(2Q).
```

`J=0` 恢复 `g_local²=ωΔ/[4 tanh(Δ/(2T))]`；铁磁极化 `T→0` 恢复
`g_local²=ω(Δ−4J)/4`（与 Koziol 二次系数条件一致）。`g_local` 只是**局部**失稳
阈值，一级跃迁可发生在 `g<g_local`。

### 3.4 零场 Dyson 展开（二、四、六阶）

在 `h=0` 的经典链上，翻转 `i` 的代价 `δE_i=−s_i[Δ+2J(s_{i−1}+s_{i+1})]`。
`Z(h)=Z_0+h²Z_2+h⁴Z_4+h⁶Z_6+…`，`f=f_0+a₂h²+a₄h⁴+a₆h⁶+…`，系数为

```text
a₂ = −(T/N)(Z₂/Z₀),
a₄ = −(T/N)[Z₄/Z₀ − (Z₂/Z₀)²/2],
a₆ = −(T/N)[Z₆/Z₀ − (Z₂/Z₀)(Z₄/Z₀) + (Z₂/Z₀)³/3].
```

**二阶**：`Z₂/Z₀ = (1/4)⟨Σ_i B₁(δE_i)⟩`，
`B₁(x)=∫₀^β(β−t)e^{−xt}dt=[βx−1+e^{−βx}]/x²`。

**四阶**（含关键修正）：四翻路径为单点四次或两点各两次。**非相邻**两点因子化
为 `B₁(δE_i)B₁(δE_j)`；**最近邻**两点不因子化——双翻后的共享 Ising 键恢复
原能量，中间能量差是

```text
dE_ij = dE_i + dE_j + 4 J s_i s_j，
```

故最近邻对必须显式求 `i,i,j,j` 的六条有序路径（遗漏项从 `O(J²)` 开始；2026-11-22
的完全因子化公式因漏掉此项而整体撤回）。通用形式：

```text
Z₄/Z₀ = (1/16)⟨ Σ_i I₄(δE_i) + Σ_{i<j} K₄(i,j) ⟩,
```

其中单点四翻的虚时间积分为 `I₄(x)=∫_{u+v+w≤β}(β−u−v−w)e^{−x(u+v)}dudvdw`（含
全部退化分支的闭式），`K₄` 对非邻为 `B₁B₁`、对邻为六路径和（合流单纯形核，见
§4）。

**六阶**：回返路径类型为 `{i⁶}`、`{i⁴j²}`、`{i²j²k²}`（含最近邻中间能量修正）。
每条有序路径的虚时间积分用 Hermite 合流差商

```text
F_m(d_0,…,d_m) = (−1)^m [d_0,…,d_m] exp(−βx)
```

（`d_k` 为中间相对能量，`[·]` 为差商，重节点用合流导数；60 位 Decimal 实现）。
由此 `a₆` 对有限环精确，无限链值以 `N` 收敛逼近。

**腔泛函系数**：`Φ_T(φ)=Φ_T(0)+[ω+16g²a₂]φ²+256g⁴a₄φ⁴+4096g⁶a₆φ⁶+…`。
`a₄` 的符号在 `g_local` 处决定局部失稳阶数（正=连续、负=一级）；热三临界点的
局部必要条件为 `a₂=0`（即 `g=g_local`）且 `a₄=0`、`a₆>0`。

### 3.5 一级前驱极小的 Landau 塌缩

在 `a₄<0` 的一级侧，`g_equal(h)²=ω/[16(−a₂−a₄h²−a₆h⁴)]` 的内点极小位于

```text
h*² = −a₄/(2a₆),
depth = g_local − g_equal(h*) ≈ g_local · a₄² / (8 a₆ |a₂|)。
```

即**内点极小的位置与深度按零场系数定量塌缩**，`a₄→0` 时极小连续退缩至
`h→0`——这是"一级前驱极小在热三临界候选点消解"的定量判据（热侧与零温侧共用）。

### 3.6 零温基线（Koziol/Langheld 换算）

按 Koziol（2026）式 (1) 的 `ε=Δ/2`、`J_K=−J`、`g_K=g` 换算，极化铁磁正常态附近

```text
e_spin(0,h) = J−Δ/2 − h²/(8A) + (Δ/2+J) h⁴/(128 A³B) + O(h⁶),
A = Δ/2−2J,  B = Δ/2−J,
g_local² = ω(Δ−4J)/4,  四次系数在 Δ=−2J 变号,
g_tc² = −3ωJ/2（Δ=−2J 处，六次系数 7ω³/(180J²)>0）。
```

`Δ=0` 的可积极限（横场 Ising）：`e_spin(0,h)=−(1/π)∫₀^π√[K²+Γ²−2KΓcos k]dk`
（`K=−J, Γ=h/2`），全局一级点由 `min_h g_equal(h)` 给出
`g_c=.4090436682`（Koziol 原文值逐位复现）。

## 6. 误差分析与验证边界

1. **数值可靠区间**：零场热系数直接公式仅 `T≳0.1` 可靠（活化构型贡献的
   `e^{±β}` 中间乘积在低温超出双精度）；`T→0` 用解析锚点，不直接求值。
2. **误差等级**：所有近等能误差为**数值诊断级**（ED `N` 收敛、NLCE 与 ED 差、
   转移两窗口差），不是严格误差界；严格界需独立 SSE/有限温 MPS 实现。
3. **转移矩阵限制**：在重入窄袋的极小场（深度 `1e-9–1e-11`），`M≤20` 外推窗口
   漂移约 `3.9e-6`，大 3–5 个量级，不参与裁决。
4. **双精度 ED 极限**：`.40024` 在 `N=12→14` 翻号，同类双精度有限环加尺寸收益
   不足（决策已冻结）；端点邻域需高精度响应/张量网络方法。
5. **离散扫描**：不能排除任意窄的未采样极小；黄金分割假定单括区单极小。
6. **外推非严格**：AFM 三点外推、`a₆` 无限链无闭式（有限环 `N` 收敛限定）。
7. **可复现性警告**：外部 32GB 运行使用 Python 3.13.14 而非交付的 3.12（源码与
   输入哈希全部匹配，结论分级未受影响）；正式引用末尾数位可复跑 `.4001` 交叉。
