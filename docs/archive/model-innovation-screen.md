# FT-TC 的模型级创新筛选

更新：2026-11-18。此页是**备选模型审计**，不是新增正式研究路线或发现。当前优先级仍为 `zz/z/x` 原模型的 P0 有限温文献缺口与方法可行性检查，见[项目简述](../brief.md)、[逐轴核查](../../literature/ft-tc-axis-survey.md)。本页取 `ℏ=k_B=1`、`σ_i^α` 为本征值 ±1 的泡利算符、`N→∞`；腔耦合均按 `1/√N` 缩放。

## 先排除表面上的“新模型”

1. **只改交错耦合的符号不够。** 对偶数 `N` 的双分格周期链，取 `H_spin=JΣ_iσ_i^zσ_{i+1}^z+h_zΣ_iσ_i^z` 和单模 `H_c=gXΣ_i(-1)^iσ_i^x/√N`；单位变换 `U=∏_{i∈奇数}σ_i^z` 使奇数格 `σ_i^x→-σ_i^x`，同时保留全部 `σ^z` 项，因此 `UHU†` 就是均匀 `gXΣσ_i^x/√N` 模型。需有不可同时规约的其他耦合或**幅值**变化，才构成新结构。此为本项目算符推断，待在模型文档中复算边界条件。
2. **同一光场正交分量的静态二次项不够。** `D X²-ξ X²` 可在稳定域由压缩变换并入改参后的腔模型；Chen 等（2021）补充 Note 1、Langheld 等（2025）补充 §IV、Leibig 等（2026）式 (2)–(3) 已给此结构。见[主张 C01–C03](../claims.md)。
3. **单模耦合轴任意倾斜不自动产生新对称相。** 若改为 `gXΣ_i(cosθ σ_i^x+sinθ σ_i^z)/√N` 且已有 `h_zΣσ_i^z`，一般 `θ` 使原来将 `X,σ^x` 同时反号的宇称变换失效；需先判定是否只剩显式偏置和交叉，不能沿用原 `FT-TC` 的正常—超辐射 `Z₂` 相界语言。此为对称性分析推断，尚未做完整文献查重。

## 可进一步查重的非等价扩展

| 备选结构（仅示意） | 为什么可能与原模型不同 | 已有先例与风险 | 当前建议 |
| --- | --- | --- | --- |
| **A. 两子晶格腔耦合幅值**：`X[g_AΣ_{i∈A}σ_i^x+g_BΣ_{i∈B}σ_i^x]/√N`，`|g_A|≠|g_B|` | 局域 `z` 旋转只改变符号，不能把两个不同的绝对幅值化为均匀耦合；可能形成非平凡的两子格响应与热分支 | [Caballero‑Benitez（2026）arXiv:2603.13693v3](https://arxiv.org/html/2603.13693) 式 (1)、图 1–2 已研究受泵浦空间耦合模式与关联；其哈密顿量在泵浦旋转系，不能直接当作无泵浦平衡热相图，但会限制“空间调制首次”主张 | **最小模型级备选**。先检索同样的平衡两子格幅值模型，再证明新增热边界或可测量量不能由均匀模型推出；若只有参数重标定则停止 |
| **B. 两独立腔模耦合不同空间模式**：`X_0g_0Σσ_i^x/√N+X_πg_πΣ(-1)^iσ_i^x/√N` | 只能用局域旋转交换两种模式，不能同时消去二者；可产生两个自洽场和竞争的全局自由能极小值 | Caballero‑Benitez（2026）式 (1)、图 2 已涉及受泵浦多空间模式；平衡双模需重新说明微观来源、`A²` 矩阵与稳定性。计算维度明显增加 | 有潜力但**暂不启动**；只有 A 与原 `FT-TC` 均查重失败时再考虑 |
| **C. 受挫交换**：`J_1Σσ_i^zσ_{i+1}^z+J_2Σσ_i^zσ_{i+2}^z`，腔仍耦合 `Σσ^x` | 物质链出现竞争尺度，可改变腔自洽自由能及中间相；需排查拓扑/浮动态与热相界 | [Leibig 等（2026）会议摘要](https://www.dpg-verhandlungen.de/year/2026/conference/mainz/part/q/session/33/contribution/6)已报告受挫锯齿链零温结果；[Hörmann（2026）§VI](https://arxiv.org/html/2606.26081)明确讨论受挫准一维扩展。不能把“加挫折”本身当新 | 物理问题强、数值难度高；本科项目暂列远期备选，须先找准与已有锯齿链结果不同的可证伪目标 |

模型是否值得写成论文，取决于**新可观测、相界或机制**是否经过全局自由能、热力学极限和独立基准支持，不能只凭哈密顿量多一个参数。真实平衡腔、受泵浦开放系统的稳态、量子模拟器有效哈密顿量的基态必须分别表述。对 A–C 尚未完成系统前向引文、微观平台与资源核算；在这三项完成前，不将其升级到 `brief.md` 或 `roadmap.md` 的活动主线。
