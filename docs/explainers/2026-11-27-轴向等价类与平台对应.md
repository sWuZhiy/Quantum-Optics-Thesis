## 1. 为什么"换个坐标系"有时成立、有时不成立

模型用三元组 `(交换轴 / 静场轴 / 腔耦合轴)` 标记。全局自旋旋转同时转动三个轴，
因此**任意两轴的夹角是不变量**。判断两个模型是否等价，看的不是字母，而是这三个夹角。

| 类 | 结构 | 代表 | 零腔极限（h=0） |
| --- | --- | --- | --- |
| **A** | 交换 ∥ 静场；腔 ⊥ 两者 | `zz/z/x`（[Langheld](../../literature/ft-tc-axis-survey.md)、Leibig、Koziol、Hörmann、本项目） | **经典** Ising 链 |
| **B** | 三轴两两正交 | `yy/z/x`（Gammelmark–Mølmer 2011）、`zz/y/x`（Rao 2025） | **量子**横场 Ising 链 |
| C | 静场 ∥ 腔 | `zz/x/x`（Granet 2023） | 场与耦合同轴 |
| D | 交换 ∥ 腔 | `zz/x/z`（Román-Roche 2021） | 腔与序参量同轴 |
| E | 无独立静场 | `zz/0/z`（Otake–Bamba 2026） | 经典链 + 腔 |

## 2. Gammelmark 与 Rao 是同一个模型

绕 x 轴（耦合轴）转 90°：`σʸ→σᶻ`、`σᶻ→−σʸ`、`σˣ→σˣ`，于是

```text
yy/z/x  ──R_x(90°)──▶  zz/(−y)/x
```

而 `Δ→−Δ` 是模型的对称性（绕 x 轴转 180°：交换 `yy` 不变、场 `z→−z`、耦合 `x` 不变），
故 `zz/(−y)/x ≅ zz/y/x`。**两者严格等价**，只是坐标标签不同。

## 3. 我们的类换不过去

`zz/z/x` 中交换轴与静场轴**重合**（夹角 0°），B 类是 90°。夹角是旋转不变量，任何坐标系
变换都改变不了。绕 x 轴转 90° 只能把我们的模型变成 `yy/y/x`——交换与场仍然平行。

更直观的判据在 h=0：

```text
A 类：  Jσᶻσᶻ + (Δ/2)σᶻ   → 两项对易，纯对角 → 经典链（转移矩阵精确解）
B 类：  Jσʸσʸ + (Δ/2)σᶻ   → 不对易       → 量子横场 Ising（Jordan–Wigner）
```

这解释了两件事：

1. **为什么 B 类可积**：固定腔位移后两个场都 ⊥ 交换轴，绕交换轴可把两个场合成一个
   等效横场 `√(Δ²+h²)`，化归标准横场 Ising 链 → JW 严格可解。
2. **为什么我们能用经典组合路径精确算 `a₂/a₄/a₆`**：零场链本身就是经典的。
   加上腔后（h≠0）变成"横场 + 纵场"的 Ising 链，**纵场破坏可积性**，只能上 ED/NLCE/
   转移矩阵——与实际所用方法一致。

## 4. 平台对应：哪一类更容易搭

三个轴在装置里各由不同机制决定：

| 轴 | 来源 | 可调性 |
| --- | --- | --- |
| 静场轴 | DC 磁场方向 / 比特失谐（量子化轴） | 容易 |
| 腔耦合轴 | 腔模偏振 | 容易，习惯取 ⊥ DC 场 |
| **交换轴** | 相互作用的**各向异性**：晶体易轴、Rydberg 修饰、耦合器设计 | **最难换** |

「我们的推断」（待核）：

| 平台 | 交换轴来源 | 归属 |
| --- | --- | --- |
| 磁偶极原子/分子（Dy、Er、Cr、极性分子） | 磁矩沿 DC 场 → `σᶻσᶻ` | **A** |
| Rydberg 修饰原子 | vdW 作用于计算基（z） | **A** |
| 超导比特阵列（Zhang 2014 类） | ZZ 交换靠耦合器 | **A** |
| 磁振子晶体（ErFeO₃，Bamba/Kim） | 晶体易轴 | **A** |
| B 类配置 | 易轴 ⊥ DC 场 | **B** |

要点：**A 类不需要额外设计**——场轴与交换轴由同一个自旋自由度决定，天然同向；
**B 类需要刻意把 DC 场拧到垂直方向**。A 类也正是 Langheld/Leibig/Koziol 等零温文献
采用的模型类。

对实验更有利的一点：A 类零腔极限经典，**量子性全部由腔提供**，相变是"腔驱动"的，
不存在本征横场 Ising 量子临界点来干扰；B 类零腔就自带一个 QCP。此外 A 类可用 DC 场
单向调 `Δ/|J|` 扫过三临界 `Δ=−2J`，不动交换强度。

## 5. 一个必须记住的限制

一维短程链在 `T>0` 没有自发长程序（[Araki 1969](../claims.md)）。有限温仍有相变，
是因为**腔耦合全连接**（所有自旋共享一个模），在平均场/热力学极限意义上产生集体转变。
所以实验上应看**集体可观测量**（腔光子数 `n/N`、整体磁化），而不是真正的长程序。
这也说明"大量原子共享一个腔模"的装置天然适合 A 类。
