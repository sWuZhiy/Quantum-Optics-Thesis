# 解释材料（explainers）

本目录存放 **AI 为帮助用户理解而写的整理性文档**。它们不推进项目，也不是项目证据。

## 什么放这里

- 用户对某个环节有疑问，AI 把已有内容重新组织、换角度讲清楚的说明；
- 对代码、数据结构、数值流程、历史决策的“导读”；
- 对某个物理概念在本项目中的具体含义的梳理。

## 什么不放这里

| 内容 | 正确位置 |
| --- | --- |
| 新的数值结果、推导或文献结论 | `results/runs/` + `docs/claims.md` + `docs/log.md` |
| 项目自己的模型与推导 | `manuscript/theory/` |
| 被取代的旧文档 | `docs/archive/` |
| 当前目标、主张、路线、决定 | `docs/` 活动层 |

## 规则

1. **非权威**：不得作为证据被 `claims.md`、`roadmap.md` 或论文引用。
2. **只重组，不新增**：解释材料只能引用已有内容并给出链接；若写的过程中产生了新结论或新数值，
   必须移入上表的权威位置，不能只留在这里。
3. **默认不读**：AI 开始新一轮工作时不必阅读本目录；用户点名时才查。
4. **命名**：`YYYY-MM-DD-主题.md`，便于追溯当时的状态。
