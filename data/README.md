# 数据

`raw/` 保存原始输入，不能覆盖；`processed/` 保存可由代码重新生成的中间数据。两者默认不提交 Git，需另行备份。每套数据应有来源、单位、采集或生成日期、处理脚本和参数说明。

## 与运行结果的分工

- `raw/<数据集名称>/`：外部实验、作者共享数值表或从文献图中提取的数据。保留来源文件；数字化提取须注明工具和误差，不能称作作者原始数据。论文 PDF 仍在 `literature/`。
- `results/runs/<运行编号>/`：本项目单次仿真生成的原始输出和探索图，不另复制一套到 `raw/`。
- `processed/<汇总名称>/`：处理外部输入，或把多个运行合并为收敛表、相界候选表等。保存输入清单、处理命令和脚本版本，能够重新生成。

## 数据索引

目前尚无研究数值数据集，也未配置独立数据备份。产生第一套数据时在本页登记：`数据集编号／来源或输入运行编号／本地位置／单位与字段／处理脚本及配置／验证状态／备份位置与日期`。

索引说明提交 Git；实际数据目录被忽略。大计算前先落实备份，避免误以为推送仓库就已保存全部研究数据。
